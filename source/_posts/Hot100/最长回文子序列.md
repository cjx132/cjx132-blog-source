解题关键

-   定义状态: `dp[i][j]`表示只考 虑序列i~j部分的最长回文子序列长度
-   考虑转移: `dp[i][j]=max(dp[i+ 1][j],dp[i][j-1])` ；`if (a[i]==a[j]) dp[i][j]=max(dp[i][j],dp[i+1][j-1]+2)`
-   **遍历的顺序，f数组的初始化，遍历的范围从j=i+1开始，最终答案的表示`f[0][n-1]`**

# Code

```c++
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n=s.size();
        vector<vector<int>>f(n,vector<int>(n,0));

        for(int i=0;i<n;i++)f[i][i]=1;//注意初始化
        for(int i=n-2;i>=0;i--)
            for(int j=i+1;j<n;j++)//注意j从i+1开始
            {
                if(s[i]==s[j])f[i][j]=f[i+1][j-1]+2;
                else f[i][j]=max(f[i+1][j],f[i][j-1]);
            }
        
        return f[0][n-1];//注意返回的答案是什么
    }
};
```

# 复杂度分析

时间复杂度：O(n^2)

空间复杂度：O(n^2)
