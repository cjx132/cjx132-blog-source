# 题目

# 综述

-   f数组表示以nums\[i\]结尾的LIS的组合的个数，初始化为1
-   若要LIS成立，我们只要考虑nums\[j\] < nums\[i\]的情况，其他情况则不考虑
    -   (1)当`dp[j]+1 > dp[i]`时,意味着我们第一次找到这个组合
    -   (2)当`dp[j]+1 == dp[i]`时,意味着我们不是第一次找到这个组合

# Code

```c++
class Solution {
public:
    int findNumberOfLIS(vector<int>& nums) {
        int n=nums.size();
        vector<int>dp(n,1);
        vector<int>f(n,1);
        int len=1;
        for(int i=0;i<n;i++)
            for(int j=0;j<i;j++)
                if(nums[j]<nums[i])
                {
                    if(dp[j]+1>dp[i])
                    {
                        dp[i]=dp[j]+1;
                        f[i]=f[j];
                    }
                    else if(dp[i]==dp[j]+1)
                        f[i]+=f[j];
                    len=max(len,dp[i]);
                }
        int ans=0;
        for(int i=0;i<n;i++)
            if(len==dp[i])
                ans+=f[i];
        return ans; 
    }
};
```
