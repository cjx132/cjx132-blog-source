# 综述

-   每次维护一个\[l,r\]的区间，代表每跳一步，所能到达的区间

# Code

```c++
class Solution {
public:
    int jump(vector<int>& nums) {
        if(nums.size()==1)return 0;
        int l=0,r=0,step=0;
        while(l<=r){
            int max_r=0;
            for(int i=l;i<=r;i++){
                max_r=max(max_r,i+nums[i]);
            }
            l=r+1,r=max_r;
            step++;
            if(r>=(int)nums.size()-1)break;
        }
        return step;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
