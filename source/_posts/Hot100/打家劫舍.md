# 题目

![](/images/Top100/%E6%89%93%E5%AE%B6%E5%8A%AB%E8%88%8D.png)

# 综述

-   递推关系为偷前k-1个或者前k-2个+当前的最大值

# Code

```c++
class Solution {
public:
    int rob(vector<int>& nums) {
        int n=nums.size();
        if(!n)return 0;
        vector<int>f(n+1,0);
        f[1]=nums[0];
        for(int i=2;i<=n;i++)
        {
            f[i]=max(nums[i-1]+f[i-2],f[i-1]);
        }
        return f[n];
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
