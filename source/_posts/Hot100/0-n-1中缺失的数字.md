# 综述

-   寻找有序序列中**第一个**满足某条件的元素的位置：**以下代码为这种类型二分模板**
    
    对应于本题，以下代码实现：找到第一个满足nums\[i\]>i的下标
    
    ```c++
    class Solution {
    public:
        int missingNumber(vector<int>& nums) {
            int n=nums.size();
            int low=0;
            int high=n;//注意1，查找区间左闭右开
            int mid;
            while(low<high){//注意2
                mid=(low+high)/2;
                if(nums[mid]>mid)high=mid;//注意3，寻找第一个满足条件的下标
                else low=mid+1;
            }
            return low;//注意4，low和left均可
        }
    };
    ```
    

-   寻找有序序列中**最后一个**满足某条件的元素的位置（**返回值需要-1**）：**以下代码为这种类型二分模板，注意和上述代码中low,high位置区别**
    
    **本题变形**：找到最后一个nums\[i\]==i的下标，代码如下
    
    ```c++
    class Solution {
    public:
        int missingNumber(vector<int>& nums) {
            int n=nums.size();
            int low=0;
            int high=n;//注意1，查找区间左闭右开
            int mid;
            while(low<high){//注意2
                mid=(low+high)/2;
                if(nums[mid]==mid)low=mid+1;//注意3，寻找最后一个满足条件的下标
                else high=mid;
            }
            return low-1;//注意4，low和left均可，此时需要减一
        }
    };
    ```
    

-   寻找有序序列中满足某条件的元素的位置（**防止mid溢出的方法**）：**以下代码为这种类型二分模板**
    
    ```c++
    int binarySearch(int A[],int left,int right,int x){
    	int mid;
    	while(left<=right){
    		mid=(left+right)/2;//mid=left+(right-left)/2;防止mid溢出
    		if(A[mid]==x)return mid;
    		else if(A[mid]>x)right=mid-1;
    		else left=mid+1;
    	}
    	return -1;
    }
    ```
