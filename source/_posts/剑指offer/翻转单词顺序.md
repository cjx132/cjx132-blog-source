# 综述

1.  整体反转
2.  逐个单词反转（双指针反转单词模板，对于多余的空格，判断后continue）
3.  去除中间空格**（for循环后面的i++提出来）**

# Code

```c++
class Solution {
public:
    int idx=-1;
    void rev(string &s,int i,int j)
    {
        while(i<j)
            swap(s[i++],s[j--]);
    }

    string reverseWords(string s) {
        int n=s.size();
        if(n<2)return s;
        reverse(s.begin(),s.end());

        for(int i=0;i<n;i++)//双指针反转单词模板
        {
            if(s[i]==' ')continue;//处理多余空格
            int j=i;
            while(j<n&&s[j]!=' ')j++;
            rev(s,i,j-1);
            i=j;
        }
        
        int idx=-1,l=0,r=n-1;
        while(l<n&&s[l]==' ')l++;//去除首尾空格
        while(r>=0&&s[r]==' ')r--;
        for(int i=l;i<=r;)//for循环后面的i++提出来
        {
            if(s[i]==' ')
            {
                while(i<n&&s[i]==' ')i++;
                s[++idx]=' ';
            }
            else 
            {
                s[++idx]=s[i];
                i++;
            }
        }
        return s.substr(0,idx+1);
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
-   空间复杂度：O(1)
