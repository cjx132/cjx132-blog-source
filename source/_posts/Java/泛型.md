# 泛型

-   本质是参数化类型，把类型作为参数传递
-   常见形式有泛型类、泛型接口、泛型方法
-   语法 T成为类型占位符，表示一种**引用类型(必须是引用类型)**，可以写多个逗号隔开
-   好处 1. 提高代码重用性 2. 防止类型转换异常，提高代码安全性

## 泛型类

### 泛型类定义

```java
// 写一个泛型类
public class MyGeneric<T>{
  //使用泛型T
  //1 创建变量
  T t;
  //2 泛型作为方法的参数
  public void show(T t){
    T t=new T();//报错，不能new一个T,因为不知道T的具体类型
    System.out.println(t);
  }
  //3 泛型作为方法的返回值
  public T getT(){
    return t;
  }
}
```

### 泛型类使用

```java
// 使用泛型类
public class TestGeneric{
  public static void main(String[] args){
    // 注意： 1. 泛型只能使用引用类型  2. 不用泛型类型对象之间不能相互赋值
    MyGeneric<String> myGeneric = new MyGeneric<String>();//使用泛型类创建对象
    myGeneric.t = "hello";
    myGeneric.show("hello world!");
    String string = myGeneric.getT();
    
    MyGeneric<Integer> myGeneric2 = new MyGeneric<Integer>();
    myGeneric2.t = 100;
    myGeneric2.show(200);
    Integer integer = myGeneric2.getT();
    
  }
}
```

## 泛型接口

语法：接口名

注意：不能泛型静态常量

### 泛型接口定义:

```java
public interface MyInterface <T>{
    String name="h";
    T server(T t);
}
```

### 泛型接口实现:

方法1：指定泛型具体类型

```java
public class MyInterfaceImpl implements MyInterface<String> {

    @Override
    public String server(String s) {
        System.out.println(s);
        return s;
    }
}
```

方法2：使用泛型类

```java
public class MyInterfaceImpl2<T> implements MyInterface<T>{//具体使用时，第一个T被确定之后，传给第二个T

    @Override
    public T server(T t) {
        System.out.println(t);
        return t;
    }
}
```

### 使用：

```java
MyInterfaceImpl myInterface=new MyInterfaceImpl();
myInterface.server("方法1");

MyInterfaceImpl2<String> myInterfaceImpl2=new MyInterfaceImpl2<>();
myInterfaceImpl2.server("方法2");
```

## 泛型方法

语法： 返回值类型

### 定义

```java
public class GenericMethod {
    public <T> T f(T t){
        System.out.println(t);
        return t;
    }
}
```

### 使用

```java
GenericMethod genericMethod = new GenericMethod();
genericMethod.f("泛型方法");
```

## 泛型集合

概念：参数化类型、类型安全的集合，强制集合元素的类型必须一致

特点：

-   编译时即可检查，而非运行时抛出异常
-   访问时，不必类型转换（拆箱）
-   不同泛型之间应用不能相互赋值，泛型不存在多态
