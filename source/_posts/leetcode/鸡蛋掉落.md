-   **两条重要性质**
    
    1.  `f[i-1][s-1]`随着 s 单调递增；`f[i][j-s]`随着 s 单调递减；设函数`h(s)=max(f[i-1][s-1],f[i][j-s])`函数曲线大致为：
        
        因此，函数曲线如下。从前往后，当h(s)<h(s+1)时，s即为最优解
        
        ![image-20210815122326523](https://cjx132.github.io/picture-bed/image-20210815122326523.png)
        
    2.  当`j`增加时，`f[i-1][s-1]`不变，`f[i][j-s]`增加，因此两条曲线的交点右移，即最优解s的值也会右移。
        

# Code

```c++
class Solution {
public:
    int superEggDrop(int k, int n) {
        vector<vector<int>>f(k+1,vector<int>(n+1,INT_MAX));
        for(int i=0;i<=n;i++)
            f[1][i]=i;

        for(int i=2;i<=k;i++)
        {
            f[i][0]=0;
            int s=1;
            for(int j=1;j<=n;j++)
            {
                //while循环结束，此时max(f[i-1][s-1],f[i][j-s])<max(f[i-1][s],f[i][j-s-1]),此时s就是当前j下的最优解
                while(s<j&&max(f[i-1][s-1],f[i][j-s])>=max(f[i-1][s],f[i][j-s-1]))
                    s++;
                f[i][j]=min(f[i][j],max(f[i-1][s-1],f[i][j-s])+1);
            }
        }
        return f[k][n];
    }
};
```

# 复杂度分析

-   时间复杂度：状态数为 O(kn)，对于每个 i，寻找最优决策的均摊总时间为 O(n)，故总时间复杂度为 O(kn)。
