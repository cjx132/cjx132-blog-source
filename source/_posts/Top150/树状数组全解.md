## 树状数组的应用【重要】

### 关于树状数组的几个关键问题：

1.  使用场景？**单点更新，区间求和**
2.  区间范围是什么？下例代码中的区间是\[1,50008\]，也就是两个函数循环中的上下限
3.  单点更新如何更新？在区间\[1,50008\]内index索引位置**加上**一个数value。更新的操作是**加上**
4.  区间求和如何求和？求和函数返回的结果是区间\[1,index\]的和

-   树状数组的本质：树状数组维护了==> 一个虚拟数组区间\[1,50008\]内的前缀和
    
-   树状数组可以实现：在虚拟数组区间内某个点更新的情况下，自动的维护了虚拟数组区间\[1,50008\]内的前缀和，更新以及求和时间复杂度都是O(logn)
    
-   虚拟数组的一些解释：（1）虚拟数组长度和树状数组一致，都是\[1,50008\]；（2）虚拟数组初始值都是0；（3）虚拟数组在程序中不用定义（4）自己心里想象虚拟数组
    

### 使用树状数组时，需要搞清楚几个问题

1.  是不是必须要使用树状数组？存在要维护一个数组区间上前缀和的需求，并且区间内数组的值会更新。**使用树状数组的题目，往往存在一个特征，同一个前缀和，比如都是\[1,m\]区间的前缀和，我求解的时机不同，前缀和的结果不一样**
2.  我要维护的数组是谁，维护的区间是什么，这个数组的下标是什么含义，这个数组的值是什么含义？
3.  我要在这个虚拟数组的哪个位置进行更新，更新时加上多少？
4.  每次更新前缀和都会改变==>我们什么时候求解前缀和，每次更新之后都求解吗？求哪个区间的前缀和？

### 总结

总的来说，把树状数组当作一个常用的数据结构，比如栈，了解他的特性和应用场景，就能够做出对应的题目了。

//树状数组getSum函数模板
    //返回前index个整数之和
    public int getSum(int index) {
        int sum = 0;
        for (int i = index; i >= 1; i -= i & (-i)) {//注意是i>0而不是i>=0
            sum += C[i];
        }
        return sum;
    }

    //树状数组add函数模板
    //add函数将第index个整数加上value:单点更新
    public void add(int index, int value) {
        for (int i = index; i <= 50008; i += i & (-i)) {//注意i必须能取到n
            C[i] += value;
        }
    }
```

class NumArray {
public:
    int n;
    vector<int>C;//树状数组
    vector<int>temp;
    NumArray(vector<int>& nums) {
        n=nums.size();
        C=vector<int>(n+1,0);
        for(int i=1;i<=n;i++){
            add(i,nums[i-1]);//维护虚拟数组区间为[1,n]。这一步是给虚拟数组区间赋初始值
        }
        temp=nums;//仅仅是nums数组的复制，提升其在类中的作用域，别无它用
    }

    void update(int i, int val) {
        add(i+1,val-temp[i]);//对应add更新的虚拟数组索引是i+1，要加上的值是val-A[i];
        temp[i]=val;//别忘了要更新，否则下次出错
    }

    void add(int i, int val) {//模板,维护区间下限是1
        for(i;i<=n;i+=i&(-i)){
            C[i]+=val;
        }
    }
    int sum(int i){//模板,维护区间下限是n
        int ret=0;
        for(i;i>=1;i-=i&(-i)){
            ret+=C[i];
        }
        return ret;
    }

    int sumRange(int i, int j) {//其实是求虚拟数组[i+1,j+1]的区间和
        return sum(j+1)-sum(i);
    }
};

/**
 * Your NumArray object will be instantiated and called as such:
 * NumArray* obj = new NumArray(nums);
 * obj->update(i,val);
 * int param_2 = obj->sumRange(i,j);
 */
```
