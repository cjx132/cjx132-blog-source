# Code

```c++
class Solution {
public:
    int findRepeatNumber(vector<int>& nums) {
        int n=nums.size();
        for(int i=0;i<n;i++){//把下标i想成一个一个的抽屉，抽屉i中放的数必须和i相等
        //接下来，我们要做的事：判断一个数是不是放在了正确的抽屉里，如果不是，就把这个数放在正确的抽屉里
            

           //我们要判断nums[i]是否放对了抽屉：当前判断的数是nums[i],当前的抽屉是i

            while(nums[i]!=i){//说明现在判断的这个数，放错了抽屉，不应该在这里；现在判断的这个数应该放在下标为nums[i]的抽屉里
                if(nums[i]==nums[nums[i]])return nums[i];//这时发现，下标为nums[i]的抽屉里已经放着同样的数，那么满足条件，直接返回
                swap(nums[i],nums[nums[i]]);//把这个数放在正确的抽屉里，同时，我们还要循环判断被交换过来的数是不是放在了正确的地方，回到上面的循环
            }
        }
        return -1;
    }
};
```

# 复杂度分析

-   时间复杂度：O(N)，这里 N 是数组的长度。虽然 for 循环里面套了 while，但是每一个数来到它应该在的位置以后，位置就不会再变化。这里用到的是均摊复杂度分析的方法：如果在某一个位置 while 循环体执行的次数较多，那么一定在后面的几个位置，根本不会执行 while 循环体内的代码，也就是说最坏的情况不会一直出现。
    
-   空间复杂度：O(1)
