# 综述

-   后续遍历思想的应用（在之前结果的基础上解决现在的问题）

# Code

```c++
class Solution {
public:
    string countAndSay(int n) {
        if(n==1)return "1";//终止条件
        string str=countAndSay(n-1);//后续遍历，必须先知道之前的结果
        int i=0;
        string ans;
        int cnt=1;
        while(i<str.size()){
            cnt=1;//计数
            while(i+1<str.size()&&str[i+1]==str[i]){
                cnt++;
                i++;
            }
            ans.push_back(cnt+'0');
            ans.push_back(str[i]);
            i++;
        }
        return ans;
    }
};
```
