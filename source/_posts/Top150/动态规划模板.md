# 动态规划入门

## 满足的条件

> 1.  子问题范围更小，且子问题个数有限
> 2.  **最优子结构**：**原问题的目标值，一定是由子问题的目标值转移而来**
> 3.  **无后效性**：**子问题的目标值求解仅局限于子问题的规模，与由哪个母状态转移而来无关**

## 记忆化搜索

> 优点是：
> 
> 记忆化搜索可以实现然而普通递推不能实现的问题（或实现起来非常麻烦的问题）
> 
> **记忆化搜索通常是用在递推关系不那么明确的情况下，使用记忆化可以避免考虑复杂的DP顺序**
> 
> 缺点是：
> 
> 带来系统栈占用，导致程序性能下降。

## 递推

> 常见于需要**优化**（**重点**）的DP
> 
> 保证求解状态的时候，子问题都已经被计算过
> 
> **需要考虑如何枚举，才能先计算出规模更小的子问题**
> 
> 通常有这样一个技巧：**状态转移方程中，如果是减法，就正序计算；如果是加法，就倒序计算。（优化空间复杂度时除外）**

## 复杂度

> 无论递推还是递归本质都是遍历整个图
> 
> 复杂度就是遍历这个图的复杂度
> 
> **点数：状态数**
> 
> **边数：状态数\*转移数**
> 
> **复杂度：状态数\*转移数**

## 解题步骤

> 1.  定义问题状态:定义问题的状态（**也就是递归树中的点**），以及目标值
> 2.  考虑状态转移:考虑当前状态做出的选择（**也就是递归树中的边**），得到当前状态转移成的子状态，问题规模得到减小。
> 3.  递归或递推解决子问题:解决规模更小的子问题，并通过子问题的结果更新答案。定义最小的子问题的初始值。

## 经典例题

-   最长连续上升子序列
    
    > 1.  定义状态: dp\[i\]表示以位 置i结尾的最长连续上升子序列长度
    > 2.  考虑转移: if a\[i\]>a\[i-1\]: dp\[i\]=dp\[i-1\]+1 else dp\[i\]=1
    
-   最长上升子序列
    
    > 1.  定义状态: dp\[i表示以位 置i结尾的最长上升子序列长度
    > 2.  考虑转移: for each j<i if a\[i\]>a\[j\]: dp\[i\]=dp\[j\]+1
    
-   最长回文子序列
    
    > 1.  定义状态: `dp[i][j]`表示只考 虑序列i~j部分的最长回文子序列长度
    > 2.  考虑转移: `dp[i][j]=max(dp[i+ 1][j],dp[i][j-1])` ；`if (a[i]==a[j]) dp[i][j]=max(dp[i][j],dp[i+1][j-1]+2)`
    
-   最长公共子序列
    
    > 1.  定义状态: `dp[i][j]`表示只考虑第一个序列的前i个，第二个序列的前j个的答案
    > 2.  考虑转移: `dp[i][j]=max(dp[i-1][j],dp[i][j-1])` ；`if (a[i]==b[j]) dp[i][j]=max(dp[i][j],dp[i-1][j-1]+1)`
    

## 总结

> 1.  动态规划本质即为递归子问题+备忘录空间换时间
>     
> 2.  三步解题法:定义**状态（根据经验，熟悉几种dp模型）**，**重点：考虑转移（思路，去想当前状态或问题有哪几种子问题）**，递归/递推
>     
>     > 1.  **状态的定义一般根据经验，熟悉几种dp模型**
>     >     
>     > 2.  转移：从集合的角度去想**当前状态有哪几种子问题（分治的思想）**，考虑当前状态的子问题时要做到**不重不漏**。
>     >     
>     >     > **很重要的划分依据：”最后”**
>     >     
>     
> 3.  **递归写法为记忆化搜索，递推写法为从小状态枚举到大状态**
>     
> 4.  复杂度为状态\*转移
>

# 背包模型

01背包和完全背包理解状态和状态转移即可，至于空间复杂度优化可以自己优化

多重背包知道二进制优化即可，即如何转化为01背包问题

01背包： `dp[i][j]=max(dp[i-1][j],dp[i-1][j-v]+w)`

完全背包：`dp[i][j]=max(dp[i-1][j],dp[i][j-v]+w)`

## 01背包

每种物品只有一个，只能取一次

### code

朴素写法：

```c++
for(int i=1;i<=N;i++){
    for(int j=0;j<=V;j++){
        dp[i][j]=dp[i-1][j];
        if(j>=cost[i]){
            dp[i][j]=max(dp[i][j],dp[i-1][j-cost[i]]+value[i]);
        }
    }
}
cout<<dp[N][V]<<endl;
```

优化写法：注意遍历顺序是**倒序**

```c++
for(int i=1;i<=N;i++){
    for(int j=V;j>=0;j--){
        dp[j]=dp[j];
        if(j>=cost[i]){
            dp[j]=max(dp[j],dp[j-cost[i]]+value[i]);
        }
    }
}
cout<<dp[V]<<endl;
```

### 复杂度

-   时间复杂度：O(NV)
    
-   空间复杂度：O(V)

优化写法

注意遍历顺序是 **正序**

```c++
for(int i=1;i<=N;i++){
    for(int j=0;j<=V;j++){
        dp[j]=dp[j];
        if(j>=cost[i]){
            dp[j]=max(dp[j],dp[j-cost[i]]+value[i]);
        }
    }
}
cout<<dp[V]<<endl;
```

### 复杂度

-   时间复杂度：O(NV)
-   空间复杂度：O(V)

# 区间DP

## 转移思想1==>枚举k进行划分

先对小区间进行求解，然后再利用小区间的最优解**合并**求得大区间的最优解。**区间dp的思想类似于记忆化搜索->迭代k->后续遍历（包含合并操作）**

### 模板

1.  定义状态：状态为DP(L,R)表示(L~R)区间的最优解
    
2.  考虑转移：转移为枚举区间划分点**DP(L,R)=DP(L,K)+DP(K+1,R)+cost(L,R,K)**
    
    > **k的范围的确定这样想：我需要划分为子问题，因此新划分的区间要比当前的小**\==>思考一下石子合并问题的k的范围
    
3.  递归递推求解子状态：递推为从短的枚举到长的，同时思考区间长度为1的初始化问题==>思考一下石子合并问题的枚举
    
4.  复杂度分析：状态O(N^2) 转移O(N)，总复杂度O(N^3)
    
5.  结合石子合并例题即可理解透彻
    
6.  **写代码注意的地方【重要】**
    
    > 1.  **初始化dp数组为最大或者最小**
    > 2.  **如何划分区间；K的取值范围(要保证：不能划分之后问题规模没有减小，不能出现和原问题相同的子问题)**
    > 3.  **枚举区间时从区间长度为2的地方开始枚举（不一定是2，具体问题具体分析，划分多边形问题从3开始，恐狼先锋从1开始）**
    > 4.  **枚举区间之前，先处理枚举起点之前的dp数组的值**
    > 5.  **求最大最小值（遍历K之前）之前要先给定一个极小或者极大值**
    

### 经典例题

-   石子合并

> 状态及状态转移容易想出
> 
> **初始值`dp[index][index]=0`**，长度为1初始化为0
> 
> 使用递推要先枚举区间长度（**本题区间长度从2开始枚举**）；再枚举左端点（也就确定了右端点）；再枚举区间内的k求出当前的最小值（需要注意k的范围）
> 
> **k的范围的确定这样想：我需要划分为子问题，因此新划分的区间要比当前的小**

-   环状石子合并（洛谷P1880）递归递推代码参考本机代码

> 1.  **复制一份原数组，追加到后面即可（这种思想对于解决环状问题很有用）**。之后求\[0,2n-1\]区间的解。
> 2.  1求出的结果中遍历其中区间长度为n的dp数组的值，求出最小即可

-   矩阵乘法

> `dp[L][R]`矩阵区间L~R乘起来最少次数
> 
> `cost(L,R,K)=a[L]*a[K+1]*a[R+1]`含义是：L~K区间的矩阵与K+1~R区间的矩阵，这两个矩阵乘起来的花费
> 
> 需要注意的问题和石子合并问题一样，代码编写基本相同

-   划分多边形
    
    > `dp[L][R]`矩阵L~R点构成的多边形的最优值
    > 
    > `cost(L,R,K)=w[L]*w[K]*w[R]`
    > 
    > 区间长度从3开始枚举，区间长度小于3的都初始化为0
    > 
    > k的取值范围如下：
    > 
    > ```c++
    > for(int k=left+1;k<right;k++){
    >     	res=min(res,dp[left][k]+dp[k][right]+A[left]*A[k]*A[right]);
    > }
    > ```
    

## 转移思想2==>和L、R左右边界有关（回文、染色相关）

### 经典例题

-   最长回文子序列
    
-   删除回文**子串**
    
    > 题目
    > 
    > ![删除回文子串](https://pic2.zhimg.com/v2-5e39d4aa37e0e0dc8867c4a831305b68_1440w.jpg?source=172ae18b)
    > 
    > 状态转移方程
    > 
    > `dp[L,R]=min(dp[L,K]+dp[K+1,R])`
    > 
    > `if(a[L]==a[R]) dp[L,R]=min(dp[L,R],dp[L+1,R-1])`
    
-   木板染色
    
    > 给定一个长度为N的木板，初始每个格子都没有颜色，每次可以选择一个连续区间(L,R)染上颜色，问最少多少次操作可以染成目标木板。  
    > `dp[L][R]`表示将L~R从全没有颜色染到目标颜色所需最少次数  
    > `dp[L,R]=min(dp[L,K]+dp[K+1,R])`  
    > `if(a[L]==a[R]) dp[L,R]=min(dp[L,R],dp[L+1,R],dp[L,R-1])`
    
-   恐狼先锋：HDU5115
    
    > `dp[L][R]`为杀死L到R的狼所受到的伤害，然后区间在\[L,R\]内枚举k作为\[L,R\]区间中最后一只被杀死的狼，此时最后一只被杀死的狼不会有额外的buff。但是\[L,R\]区间的左右端点L和R会受到区间之外的额外buff。因此有状态转移方程
    > 
    > `dp[L,R]=min(dp[L,R],dp[L,k-1]+dp[k+1,R]+b[L-1]+b[R+1]+a[k]);`
    > 
    > 从区间长度为1开始枚举
    > 
    > 区间长度为0的处理：`if(L>R)` `dp[L][R]=0`
    
-   木板染色2：HDU2476
    
    > 1.  先求出把一个空白串刷成B串所需要的最少操作次数，并且不仅仅是整个区间的最少操作次数需要记录，而且每个子区间的最少操作次数也需要记录。记录在dp\[l\]\[r\]数组中。
    >     
    > 2.  A串与空白串所不同的地方在于：A串在某些地方可能与B串相同，在这些地方，A串就不要再去刷了，而空白串则必须要刷。所以A串的最少操作次数就可以这样求：
    >     
    >     从第一个位置开始递推，假设当前递推到第i个位置。
    >     
    >     1) 如果在第i个位置上，A串与B串相同，那么在i处就不需要处理，直接 f\[i\] = f\[i-1\] 。
    >     
    >     2) 如果在第i个位置上，A串与B串不同，那么表明第i个字符必须刷，要刷的话，就要考虑刷多少，即需要考虑往前刷多少个？枚举取最优值。
    >
