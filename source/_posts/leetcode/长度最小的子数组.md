# 综述

[参考](https://www.acwing.com/solution/content/268/)

-   对于当前i来说,j表示最左边的保证`[j,i]`区间和小于target的值。那么j-1就是对于当前i来说最优的满足区间和大于等于target的值，更新。
-   **由于 j 是随着 i 增大单调不减的，故我们可以用双指针。**和**无重复字符的最长子串**类似

# Code

```c++
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n=nums.size();
        int res=n+1;
        int cur=0;
        for(int i=0,j=0;i<n;i++)
        {
            cur+=nums[i];
            while(j<=i&&cur>=target)
            {
                cur-=nums[j];
                j++;
            }
            if(j>0)
                res=min(res,i-j+2);
        }
        if(res==n+1)return 0;
        return res;
    }
};
```
