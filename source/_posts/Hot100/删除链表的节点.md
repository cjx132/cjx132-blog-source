# 综述

-   dummy节点的设置：next指针指向头结点

# Code

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode* deleteNode(ListNode* head, int val) {
        ListNode* dummy=new ListNode(0);
        dummy->next=head;//设置虚拟节点，指向头指针
        ListNode* cur=head;
        ListNode* pre=dummy;
        while(cur){
            if(cur->val==val){
                pre->next=cur->next;
                break;
            }
            pre=cur;
            cur=cur->next;
        }
        return dummy->next;//注意
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
