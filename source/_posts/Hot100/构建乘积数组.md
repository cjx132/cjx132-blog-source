# 综述

-   非常明确的是，第i位的值位前i位的累积✖️后i位的累积
-   先从左到右累积，第i位的值位前i-1位的累积
-   再从右到左累积，第i位的值为2.的结果乘上后i-1位的累积

# Code

```c++
class Solution {
public:
    vector<int> constructArr(vector<int>& a) {
        int n=a.size();
        vector<int>ans(n);
        int t=1;
        for(int i=0;i<n;i++){
            ans[i]=t;
            t*=a[i];
        }
        t=1;
        for(int i=n-1;i>=0;i--){
            ans[i]*=t;//注意这里的区别
            t*=a[i];
        }
        return ans;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
