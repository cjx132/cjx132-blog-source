# 综述

[参考讲解视频链接](https://www.bilibili.com/video/av60897618)

二分用于寻找性质的边界（第一个或者最后一个）

**\[l,r\]都是闭区间，每次调整区间必须保证答案在区间内**

考虑问题时考虑序列中第一个满足某个条件的数（r=mid，右边界往左移找第一个），或者最后一个满足某个条件的数(l=mid，左边界往右移找最后一个)

r=mid找到的是第一个满足某个条件的数，l=mid找到的是最后一个满足某个条件的数

## 整数二分算法模板 —— 模板题 AcWing 789. 数的范围

```c++
bool check(int x) {/* ... */} // 检查x是否满足某种性质

// 区间[l, r]被划分成[l, mid]和[mid + 1, r]时使用：
int bsearch_1(int l, int r)
{
    while (l < r)
    {
        int mid = l + r >> 1;
        if (check(mid)) r = mid;    // check()判断mid是否满足性质
        else l = mid + 1;
    }
    return l;
}
// 区间[l, r]被划分成[l, mid - 1]和[mid, r]时使用：
int bsearch_2(int l, int r)
{
    while (l < r)
    {
        int mid = l + r + 1 >> 1;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    return l;
}
```

## 浮点数二分算法模板 —— 模板题 AcWing 790. 数的三次方根

```c++
bool check(double x) {/* ... */} // 检查x是否满足某种性质

double bsearch_3(double l, double r)
{
    const double eps = 1e-6;   // eps 表示精度，取决于题目对精度的要求
    while (r - l > eps)
    {
        double mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid;
    }
    return l;
}
```

## 代码形式2（**防止mid溢出的方法**）：**以下代码为这种类型二分模板**

```c++
int binarySearch(int A[],int left,int right,int x){
	int mid;
	while(left<=right){
		mid=(left+right)/2;//mid=left+(right-left)/2;防止mid溢出
		if(A[mid]==x)return mid;
		else if(A[mid]>x)right=mid-1;
		else left=mid+1;
	}
	return -1;
}
```
