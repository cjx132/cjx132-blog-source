# 综述

-   `G(i) = i ^ (i/2)`

# Code

```c++
class Solution {
public:
    vector<int> grayCode(int n) {
        vector<int>res;
        for(int i=0;i<1<<n;i++){
            res.push_back(i^(i>>1));
        }
        return res;
    }
};
```
