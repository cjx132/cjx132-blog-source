# 综述

-   **BFS:第一层是整个字符串S，第二层是S去掉一个字符形成的所有字符串，第三层是第二层字符串去掉一个字符形成的所有字符串…**
    
-   在某一层找到满足条件的字符串时，就不用往下一层找了，**但是要遍历本层所有字符串得到可能的答案**
    
-   每一层的字符串要注意使用set去重
    
-   需要加一个判断过滤掉括号之外的字符(见注释)
    
-   注意：
    
    > -   当验证到正确的字符串时，要使found等于true,因为这样的话，就等于不用再对队列中的字符串进行剪了，只要把队列中剩下的字符串进行验证就行了。
    > -   开始时，我将continue写到if(isvalid(top))的范围里了，这样的话，当队列中的其他字符串取出进行验证发现不正确时，还会继续往下减，这样就不对了，因为已经得到了进行最少步剪的步数的到的结果了。
    
-   [附上一种DFS解法，时间复杂度为O(n^2)](https://blog.csdn.net/qq508618087/article/details/50408894)
    

# Code

```c++
class Solution {
public:
    vector<string> removeInvalidParentheses(string s) {
        set<string>se;
        queue<string>q;
        vector<string>res;
        bool found=false;
        se.insert(s);
        q.push(s);
        while(!q.empty()){
            string top=q.front();
            q.pop();
            if(isvalid(top)){
                res.push_back(top);
                found=true;
            }
            //在某一层找到满足条件的字符串时，就不用往下一层找了，但是要遍历本层所有字符串得到可能的答案
            if(found)continue;
            for(int i=0;i<top.size();i++){
                if(top[i]=='('||top[i]==')'){//过滤掉括号之外的字符
                    string t=top.substr(0,i)+top.substr(i+1);
                    if(se.find(t)==se.end()){//去重
                        se.insert(t);
                        q.push(t);
                    }
                } 
            }
        }
        return res;
    }

    bool isvalid(string s){//括号匹配模板（允许字符串中有括号之外的字符）
        stack<char>st;
        for(char c:s){
            if(c=='('||c==')'){//过滤掉括号之外的字符
                if(c=='('){
                    st.push(c);
                }else{
                    if(st.empty())return false;
                    if(c==')')st.pop();
                }
            }
        }
        if(!st.empty())return false;
        return true;
    }
};
```

# 复杂度分析

-   时间复杂度：`T(n)` = `n` x `C(n, n)` + `(n-1)` x `C(n, n-1)` + … + `1` x `C(n, 1)` = `n` x `2^(n-1)`
