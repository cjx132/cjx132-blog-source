# 综述

i表示每个符合条件的区间的右端点，j表示距离i最远的满足条件的位置

存在一个单调性，i增加，j一定会增加

判断字符串是否重复使用`h[s[i]]>1`来判断

# Code

```c++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n=s.size();
        unordered_map<char,int>h;

        int res=0;
        for(int i=0,j=0;i<n;i++)
        {
            h[s[i]]++;
            while(j<=j&&h[s[i]]>1)
            {
                h[s[j]]--;
                j++;
            }
            res=max(res,i-j+1);
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(n)
