# 综述

-   记录每一位不为0的数字出现的次数
-   如果出现的次数对3取模为1，则说明只出现一次的数字此位也是1
-   将所有模3为1的位相加，得到最终结果

# Code

```c++
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int res=0;
        for(int i=0;i<32;i++){
            int cnt=0;
            for(auto n: nums){
                if((1<<i)&n){//注意不能写成if(((1<<i)&n)==1),这里不一定等1
                    cnt++; 
                }
            }
            if(cnt%3){
                res+=(1<<i);
            }
        }
        return res;
    }
};
```
