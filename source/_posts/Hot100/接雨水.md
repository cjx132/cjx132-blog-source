# 综述

## 方法一：双指针

核心思想：对于每个位置，能接的雨水量 = min(左边最高, 右边最高) - 当前高度。

关键优化：不需要预处理两个数组，用左右双指针从两端向中间移动。每次移动较短的一侧，因为较短一侧的最大值已经确定了这一侧能接的水量。

- leftmax 记录左侧最大值，rightmax 记录右侧最大值
- 如果 leftmax < rightmax，处理左指针：水量 += leftmax - height[i]，i++
- 否则处理右指针：水量 += rightmax - height[j]，j--
- 较小一侧的水量只取决于该侧的 max，与另一侧无关

## 方法二：单调栈

维护一个递减栈（存下标），当遇到比栈顶高的柱子时，说明栈顶柱子的左右两边都找到了更高的边界，可以计算这一层的雨水量。

- 弹出栈顶 t，此时栈顶就是 t 左边第一个更高的柱子，当前 i 是 t 右边第一个更高的柱子
- 雨水量 = 宽度 (i - stack.top() - 1) × 高度 (min(height[左], height[右]) - height[t])
- 相同高度的柱子连续弹出，避免重复计算


# Code

```c++
class Solution {
public:
    int trap(vector<int>& height) {
        int leftmax=0,rightmax=0;
        int i=0,j=height.size()-1;
        int res=0;
        while(i<j)
        {
            leftmax=max(leftmax,height[i]);
            rightmax=max(rightmax,height[j]);
            if(leftmax<rightmax)
                res+=leftmax-height[i++];
            else res+=rightmax-height[j--];
        }
        return res;
    }
};
```

单调栈解法

对于每个元素，找其左右两边第一个大于当前元素的下标

**当前元素（栈顶元素t），左边第一个大于当前元素的下标（栈顶下面的元素），右边第一个大于当前元素的下标（height\[i\]），三者形成雨水**

```c++
class Solution {
public:
    int trap(vector<int>& height) {
        int n=height.size();
        stack<int>stk;

        int res=0;
        for(int i=0;i<n;i++)
        {
            while(!stk.empty()&&height[i]>height[stk.top()])
            {
                int t=stk.top();
                stk.pop();
                while(!stk.empty()&&height[stk.top()]==height[t])
                    stk.pop();
                if(!stk.empty())
                    res+=(i-stk.top()-1)*(min(height[stk.top()],height[i])-height[t]);//长*高
            }
            stk.push(i);
        }
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
-   空间复杂度：O(1)
