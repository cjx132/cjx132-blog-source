速记卡片（面试前 30 分钟翻一遍）

速查
Java 并发核心
  • synchronized vs ReentrantLock：synchronized 是 JVM 层面的关键字（monitorenter/monitorexit），ReentrantLock 是 API 层面的锁，支持公平锁、响应中断、超时尝试
  • AQS：核心是 state + CLH 双向队列。独占模式（ReentrantLock）和共享模式（Semaphore/CountDownLatch）
  • 线程池 7 参数：corePoolSize · maxPoolSize · keepAliveTime · unit · workQueue · threadFactory · handler（4种拒绝策略：AbortPolicy/CallerRunsPolicy/DiscardPolicy/DiscardOldestPolicy）
  • volatile：保证可见性（MESI 缓存一致性）和禁止指令重排（内存屏障），不保证原子性
  • CAS：Compare-And-Swap，ABA 问题用 AtomicStampedReference 解决
JVM 核心
  • GC 收集器：Serial（单线程）→ Parallel（多线程高吞吐）→ CMS（低延迟，标记-清除，4步：初始标记→并发标记→重新标记→并发清除）→ G1（Region 划分，可预测停顿，Remembered Set 避免全堆扫描）
  • 类加载：加载→连接（验证+准备+解析）→初始化。双亲委派：先委托父加载器，防止核心类被篡改
  • 内存区域：堆（新生代 Eden+S0+S1 / 老年代）· 方法区/元空间 · 虚拟机栈 · 本地方法栈 · 程序计数器
MySQL 核心
  • 索引：B+树（叶子节点双向链表，范围查询快）。最左前缀原则。索引下推（ICP）减少回表
  • 事务隔离：读未提交→读提交→可重复读(MySQL默认)→序列化。MVCC 通过 undo log + 一致性视图实现快照读
  • 锁：两阶段锁协议（事务结束时才释放）。RR 级别间隙锁防幻读，RC 无间隙锁
  • 持久化：redo log（crash-safe，WAL机制）+ binlog（复制/归档）。两阶段提交保证一致性
计算机网络核心
  • TCP 三次握手：SYN → SYN+ACK → ACK。防止历史报文建立无效连接
  • TCP 四次挥手：FIN → ACK → FIN → ACK。TIME_WAIT 等待 2MSL 防止最后一个 ACK 丢失
  • HTTPS：证书验证 → 非对称加密传输会话密钥 → 对称加密通信
  • IO 多路复用：select（fd数量限制）→ poll（无限制但O(n)遍历）→ epoll（事件驱动，O(1)）
Spring 核心
  • IoC：控制反转，DI 是实现方式。三级缓存解决循环依赖（singletonObjects · earlySingletonObjects · singletonFactories）
  • AOP：动态代理（JDK 接口代理 / CGLIB 继承代理）。$Proxy0 extends Proxy implements Interface，invoke 调用 InvocationHandler
  • Spring Boot 自动配置：扫描 META-INF/spring.factories，加载 xxxAutoConfiguration，配合 xxxProperties 实现约定大于配置
算法速记
  • 二分：找第一个满足条件 mid = l+r>>1，找最后一个 mid = l+r+1>>1（防死循环）
  • DP 三步：定义状态 → 考虑转移 → 递归/递推。复杂度 = 状态数 × 转移数
  • 01背包：倒序遍历；完全背包：正序遍历
  • 回溯六步：终止→剪枝→保存→改全局变量→递归→恢复。剪枝须O(1)
  • 三路快排：lt/i/gt 三指针，循环条件 while(i<gt)，重复元素多时优于双路
