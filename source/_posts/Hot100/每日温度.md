# 综述

单调栈模板题：求左边第一个大的就倒序，右边第一个小的就正序

# Code

```c++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& T) {
        int n=T.size();
        vector<int>ans(n);
        stack<int>stk;
        for(int i=n-1;i>=0;i--)
        {
            while(!stk.empty()&&T[i]>=T[stk.top()])
                stk.pop();
            if(stk.size())ans[i]=stk.top()-i;
            else ans[i]=0;
            stk.push(i);
        }
        return ans;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
-   空间复杂度：O(n)
