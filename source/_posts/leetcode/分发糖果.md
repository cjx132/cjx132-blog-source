# 综述

-   先确定右边评分大于左边的情况（也就是从前向后遍历）
    
-   再确定左孩子大于右孩子的情况（从后向前遍历）
    
    > 为什么不能从前向后遍历呢？
    > 
    > 因为如果从前向后遍历，根据 ratings\[i + 1\] 来确定 ratings\[i\] 对应的糖果，那么每次都不能利用上前一次的比较结果了。
    

# Code

```c++
class Solution {
public:
    int candy(vector<int>& ratings) {
        int n=ratings.size();
        vector<int>res(n,1);
        for(int i=1;i<n;i++)
            if(ratings[i]>ratings[i-1])
                res[i]=res[i-1]+1;

        for(int i=n-2;i>=0;i--)
            if(ratings[i]>ratings[i+1])
                res[i]=max(res[i],res[i+1]+1);

        int ans=0;
        for(int i=0;i<n;i++)
            ans+=res[i];

        return ans;
    }
};
```
