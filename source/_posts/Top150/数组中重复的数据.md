# 综述

-   原地哈希之后，不符合哈希规则的元素就是重复的数据
-   题目中已经规定：数组中只有重复两次和重复一次的元素

# Code

```c++
class Solution {
public:
    vector<int> findDuplicates(vector<int>& nums) {
        vector<int>res;
        int n=nums.size();
        for(int i=0;i<n;i++){
            while(i+1!=nums[i]){
                if(nums[i]-1<0||nums[i]-1>=n||nums[i]==nums[nums[i]-1])break;
                swap(nums[i],nums[nums[i]-1]);
            }
        }
        for(int i=0;i<n;i++){
            if(i+1!=nums[i]){
                res.push_back(nums[i]);
            }
        }
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(N)，这里 N 是数组的长度。虽然 for 循环里面套了 while，但是每一个数来到它应该在的位置以后，位置就不会再变化。这里用到的是均摊复杂度分析的方法：如果在某一个位置 while 循环体执行的次数较多，那么一定在后面的几个位置，根本不会执行 while 循环体内的代码，也就是说最坏的情况不会一直出现。
    
-   空间复杂度：O(1)
