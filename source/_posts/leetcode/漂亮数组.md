# 题目

# 综述

-   漂亮数组：**不存在** `k` 满足 `i < k < j` 使得 `A[k] * 2 = A[i] + A[j]`
    
-   a \* A + b 也是漂亮数组
    
-   数组两两配对，左数组 \* 2 - 1 一定是奇数组，右数组 \* 2 一定为偶数组，合并一定为漂亮数组
    
    解释：如果左边的奇数组是漂亮数组，右边的偶数组是漂亮数组。合并起来后奇数+偶数是奇数，A\[k\] \* 2是偶数，所以合并后也是漂亮数组
    

# Code

```c++
/* A 是漂亮数组，则 a * A + b 也是漂亮数组 
 * A 为奇数漂亮数组，B 为偶数漂亮数组，A + B 为漂亮数组
 * 数组两两配对，左数组 * 2 - 1 一定是奇数组，右数组 * 2 一定为偶数组，合并一定为漂亮数组
 * 假设 [1] 是最小漂亮数组，按照上面规律递推得到的一定是漂亮数组。 
 * |1|1|1|1|1|1|1|1|
 * |1 2|1 2|1 2|1 2|
 * |1 3 2 4|1 3 2 4|
 * |1 5 3 7 2 6 4 8|
 */
class Solution {
public:
    vector<int> beautifulArray(int n) {
        vector<int>ans(n,1);
        part(ans,0,n-1);
        return ans;
    }
    void part(vector<int>ans, int l,int r)
    {
        if(l>=r)return;
        int mid=l + r >> 1;
        part(ans,l,mid);
        part(ans,mid+1,r);
        for(int i=l;i<=mid;i++)
            ans[i]=2*ans[i]+1;
        for(int i=mid+1;i<=r;i++)
            ans[i]=2*ans[i];
        return;
    }
};
```
