# Code

```c++
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int len=nums.size();
        int j=0;
        for(int i=0;i<len;i++){
            if(nums[i]!=0){
                nums[j++]=nums[i];
            }
        }
        while(j<len){
            nums[j++]=0;
        }
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
