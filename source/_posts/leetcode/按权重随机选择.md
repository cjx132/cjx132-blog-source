# 题目

![image-20210220233850703](https://cjx132.github.io/picture-bed/img/image-20210220233850703.png)

# 综述

-   使用前缀和
-   找到前缀和数组中第一个大于随机值的下标
-   下标值-1就是原数组中的位置

# Code

```c++
class Solution {
public:
    int sum[10010]={0};
    int n=0;
    Solution(vector<int>& w) {
        n=w.size();
        for(int i=0;i<n;i++)
            sum[i+1]=sum[i]+w[i];
    }
    
    int pickIndex() {
        int t=random()%sum[n];
        int l=0,r=n;
        while(l<r)
        {
            int mid=(l+r)/2;
            if(sum[mid]>t)r=mid;
            else l=mid+1;
        }
        return l-1;
    }
};

/**
 * Your Solution object will be instantiated and called as such:
 * Solution* obj = new Solution(w);
 * int param_1 = obj->pickIndex();
 */
```

# 复杂度分析

-   时间复杂度：O(nlogn)
-   空间复杂度：O(n)
