## 树状数组解法

-   这题是树状数组的模板题
-   参考算法笔记470页
-   重点理解代码中的注释
-   查看树状数组全解笔记
-   本题的虚拟数组就是哈希数组

**树状数组经典应用：统计序列中在元素左边比该元素小的元素个数**

**如何统计序列中在元素左边比该元素大的元素个数？事实上这等价于计算hash\[A\[i\]+1\]+…+hash\[N\]，于是getSum(N)-getSum(A\[i\])就是答案。至于统计序列中在元素右边比该元素小（或大）的元素个数，只需要把原始数组从右往左遍历就好了**

本题求解时，回答几个树状数组相关的问题:

1.  在本题中，假如我们有一个哈希数组，这个数组每一项存储的是某个元素出现的次数，当我们求解有多少数比当前数小的时候，我们只要把这个索引前面的哈希数组的值相加即可得到答案。因此，我们需要维护这个哈希数组的前缀和。在我们依次求解每个当前元素有多少数比他小时，当前元素的出现也会导致哈希数组的更新，个数加1。**而且，对于同一区间的前缀和，求解的时机不同，前缀和的结果也不同。**因此，本题中我要维护哈希数组某个区间上的前缀和，同时这个哈希数组还会更新，我需要使用树状数组
2.  维护的数组是哈希数组。维护的哈希数组的区间就是哈希数组索引的范围。由于树状数组维护的区间都是\[1,n\]，所以这个哈希数组的索引范围我们要把它变得符合树状数组的要求==>把原数组离散化得到一个新数组，保持原数组中元素大小关系不变的情况下，改变每一位置上原数组的值，使得新数组每一项的值都在\[1,n\]的区间内。也就相当于=>求解给定N个学生的分数，给他们进行排名，分数相同则排名相同。新数组的下标和原数组一致，新数组存储的值就是这N个学生的排名。新数组用A\[i\]表示1<=A\[i\]<=N。此时数组A\[i\]就可以替代原数组
3.  维护的哈希数组的索引代表A\[i\]的值，哈希数组的值代表这个元素出现的次数。哈希数组刚开始区间\[1,n\]内值都是0。对于A数组中出现的每一个数，我都要在哈希数组索引为A\[i\]的地方更新值，每次加上1，代表出的次数多了1。
4.  在每次更新时，我们都要求前缀和。求解前缀和的区间是：\[A\[i\]+1,N\]，表示当前情况下，比当前元素大的个数有多少

## 归并排序解法

```c++
class Solution {
public:
    vector<int>tmp;
    int res=0;
    int reversePairs(vector<int>& nums) {
        tmp=vector<int>(nums.size(),0);
        return merge_sort(nums,0,nums.size()-1);
    }

    int merge_sort(vector<int>& nums,int l,int r)
    {
        if(l>=r)return 0;
        int mid=(l+r)/2;
        res=merge_sort(nums,l,mid)+merge_sort(nums,mid+1,r);

        int i=l,j=mid+1,k=0;
        while(i<=mid&&j<=r)
        {
            if(nums[i]<=nums[j])
                tmp[k++]=nums[i++];
            else
            {
                res+=mid-i+1;
                tmp[k++]=nums[j++];
            }
        }

        while(i<=mid)tmp[k++]=nums[i++];
        while(j<=r)tmp[k++]=nums[j++];

        for(int i=l,j=0;i<=r;i++,j++)nums[i]=tmp[j];
        return res;
    }
};
```

## 树状数组解法

```java
class Solution {
    int[] C = new int[50009];
    int[] A = new int[50009];
    int n;

    public int reversePairs(int[] nums) {
        n = nums.length;

        //以下代码实现的操作相当于：求解给定N个学生的分数，给他们进行排名，分数相同则排名相同
        //最终得到离散之后的数组A：A数组长度为n，数组内元素范围是[1,n]，A数组中的值存储对应nums数组元素的排名
        Node[] temps = new Node[n];//结构体数组
        for (int i = 0; i < n; i++) {
            temps[i] = new Node();
            temps[i].setPos(i);
            temps[i].setVal(nums[i]);
        }

        //按照val排序
        Arrays.sort(temps, (a, b) -> {
            if(a.val < b.val)return -1;
            else if(a.val>b.val)return 1;
            else return 0;
        });

        for (int i = 0; i < temps.length; i++) {
            if (i == 0 || temps[i].val != temps[i - 1].val) {
                A[temps[i].pos] = i + 1;
            } else {
                A[temps[i].pos] = A[temps[i - 1].pos];
            }
        }

        //求解本题的关键代码
        //由于是求右边小的元素：所以倒序遍历；并且最终结果每次从头部插入

        int ans=0;
        for (int i = 0; i <nums.length; i++) {
            //这里想象一个虚拟的hash数组，这个数组的长度和树状数组C大小相同为n+1；这个数组的下标是A[i]的值，这个数组中的值是A[i]出现的次数
            //树状数组所求的前缀和其实就是这个hash数组的前缀和
            add(A[i], 1);//给虚拟hash数组下标为A[i]的地方+1，同时更新树状数组的值
            ans+=getSum(n)-getSum(A[i]);////求虚拟hash数组下标范围[A[i]+1,N]的前缀和,也就是当前比A[i]大的元素个数总和
        }
        return ans;
    }

    //树状数组getSum函数模板
    //返回前index个整数之和
    public int getSum(int index) {
        int sum = 0;
        for (int i = index; i > 0; i -= i & (-i)) {//注意是i>0而不是i>=0
            sum += C[i];
        }
        return sum;
    }

    //树状数组add函数模板
    //add函数将第index个整数加上value:单点更新
    public void add(int index, int value) {
        for (int i = index; i <= n; i += i & (-i)) {//注意i必须能取到n
            C[i] += value;
        }
    }
}
class Node {
    public int val;//序列元素的值
    public int pos;//原始序号

    public int getVal() {
        return val;
    }

    public void setVal(int val) {
        this.val = val;
    }

    public int getPos() {
        return pos;
    }

    public void setPos(int pos) {
        this.pos = pos;
    }
}
```
