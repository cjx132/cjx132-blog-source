# 综述

-   使用两个指针 node1，node2 分别指向两个链表 headA，headB 的头结点，
-   同时分别逐结点遍历，当 node1 到达链表 headA 的末尾时，重新定位到链表 headB 的头结点；
-   当 node2 到达链表 headB 的末尾时，重新定位到链表 headA 的头结点。
-   当它们相遇时，所指向的结点就是第一个公共结点。

# Code

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode *pa=headA;
        ListNode *pb=headB;
        while(pa!=pb){
            // if(pa==pb&&pb==NULL)return NULL;
            pa!=NULL ? pa=pa->next :pa=headB;
            pb!=NULL ? pb=pb->next :pb=headA;
        }
        return pa;
    }
};
```

# 复杂度分析

-   时间复杂度：O(N)
-   空间复杂度：O(1)
