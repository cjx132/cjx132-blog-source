# 综述

**注意初始化**

水平方向走m-1步，竖直方向走n-1步

方法1：组合数，从（m+n-2）中挑出m-1个

> 为防止溢出，**写成`ans=ans*j/i`的形式**；
> 
> 需要注意`ans=ans*j/i`不能写成`ans*=j/i`\=>会导致除法不精确的错误答案

方法2：动态规划，`f[i][0]`与`f[0][j]`全部初始化为1，返回`f[m-1][n-1]`的

# Code

```c++
class Solution {
public:
    int uniquePaths(int m, int n) {
        int a=m+n-2;
        int b=n-1;

        long ans=1;
        for(int i=1,j=b+1;i<=a-b;i++,j++)
            ans=ans*j/i;//不能写成ans*=j/i
        return ans;
    }
};
```
```c++
class Solution {
public:
    int f[105][105];
    int uniquePaths(int m, int n) {
        for(int i=0;i<m;i++)f[i][0]=1;
        for(int j=0;j<n;j++)f[0][j]=1;
        for(int i=1;i<m;i++)
            for(int j=1;j<n;j++)
                f[i][j]=f[i-1][j]+f[i][j-1];
        return f[m-1][n-1];
    }
};
```
