# 综述

-   **[股票问题系列全解](https://leetcode-cn.com/circle/article/qiAgHn/)**
-   和k不限次数的解法相同，注意买入时减去手续费即可
-   **注意i==0时，加入持有同样需要减去手续费**

# Code

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices, int fee) {
        int n=prices.size();
        int hold=-prices[0]-fee, un_hold=0;
        for(int i=1;i<n;i++)
        {
            un_hold=max(un_hold,hold+prices[i]);
            hold=max(hold,un_hold-prices[i]-fee);
        }
        return un_hold;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
-   空间复杂度：O(1)
