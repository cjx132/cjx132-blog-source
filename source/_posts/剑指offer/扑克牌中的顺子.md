# 综述

`nums[4]-nums[k]<=4;`满足条件

# Code

```c++
class Solution {
public:
    bool isStraight(vector<int>& nums) {
        sort(nums.begin(),nums.end());

        int k=0;
        while(k<=4&&nums[k]==0)k++;

        for(int i=k+1;i<=4;i++)//从k+1开始避免i-1越界
            if(nums[i]==nums[i-1])
                return false;
        
        return nums[4]-nums[k]<=4;
    }
};
```
