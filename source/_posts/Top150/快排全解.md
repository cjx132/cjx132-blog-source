# 双路快排

-   排序区间是左闭右闭区间

```c++
void quick_sort(int q[], int l, int r)
{
    if (l >= r) return;

    int i = l - 1, j = r + 1, x = q[l + r >> 1];//1.下取整，不能出现x=q[r]的情况
    while (i < j)
    {
        do i ++ ; while (q[i] < x);
        do j -- ; while (q[j] > x);
        if (i < j) swap(q[i], q[j]);
    }
    quick_sort(q, l, j), quick_sort(q, j + 1, r);//2.和1对应的区间划分，必须是这样
}
```

# 三路快排（荷兰国旗问题）

-   排序区间是左闭右闭区间
    
-   每一次partation的结果是：**【partitation结果区间需牢记】**
    
    > 1.  less than, arr\[low…lt\] < temp，初始状态为空
    > 2.  greater than, arr\[gt…high\] > temp，初始状态为空;
    > 3.  arr\[lt+1…i) == temp
    
-   循环条件为`while (i < gt)`，不能弄错（1.不含等号，2.是gt，不是high）
    
-   **lt与gt的初始值须注意**
    

```c++
void sort3(vector<int>& arr,int low,int high){
        if(low<high){//区间元素个数大于等于2才有排序的必要
            // 随机在arr[low...high]的范围中, 随机选择一个数值作为标定点pivot;
            // 递归树不平衡问题;
            swap(arr[low], arr[rand() % (high - low + 1) + low]);//注意+1的位置
            int temp = arr[low];
            int lt = low - 1;     // less than, arr[low...lt] < temp，初始状态为空;
            int gt = high + 1; // greater than, arr[gt...high] > temp，初始状态为空;
            int i = low;    // arr[lt+1...i) == temp

            while (i < gt) {
                if (arr[i] < temp) {
                    swap(arr[i++], arr[++lt]);
                }
                else if (arr[i] > temp) {
                    swap(arr[i], arr[--gt]);
                }
                else { // arr[i] == temp
                    ++i;
                }
            }
            sort3(arr, low, lt);
            sort3(arr, gt, high);
        }
    }
```

# 归并排序

```c++
void merge_sort(int q[], int l, int r)
{
    if (l >= r) return;

    int mid = l + r >> 1;
    merge_sort(q, l, mid);
    merge_sort(q, mid + 1, r);

    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r)
        if (q[i] <= q[j]) tmp[k ++ ] = q[i ++ ];
        else tmp[k ++ ] = q[j ++ ];

    while (i <= mid) tmp[k ++ ] = q[i ++ ];
    while (j <= r) tmp[k ++ ] = q[j ++ ];

    for (i = l, j = 0; i <= r; i ++, j ++ ) q[i] = tmp[j];//最后一步不能忘记
```

# 区别

-   在数组中含有较多重复元素时，三路快排效率优于双路快排
