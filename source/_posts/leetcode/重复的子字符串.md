# 综述

-   外层循环枚举每一个循环节的长度
-   内存循环检查是否匹配

# Code

```c++
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        int n=s.size();

        for(int i=1; i*2<=n ;i++)
        {
            if(n%i==0)
            {
                bool f=true;
                for(int j=i;j<n;j++)
                {
                    if(s[j]!=s[j-i])
                    {
                        f=false;
                        break;
                    }
                }
                if(f)return true;
            }
            
        }
        return false;
    }
};
```
