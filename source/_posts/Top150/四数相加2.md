# 题目

# 综述

-   挑选其中两个数组，定义一个哈希表，key存储和，value存储这个和出现的次数
-   挑选另外两个数组，计算所有可能的和，取和的相反数，判断哈希表中是否存在，存在则相加

# Code

```c++
class Solution {
public:
    int fourSumCount(vector<int>& A, vector<int>& B, vector<int>& C, vector<int>& D) {
        int a=A.size();
        int b=B.size();
        int c=C.size();
        int d=D.size();
        int res=0;
        unordered_map<int,int>mp1;

        for(int i=0;i<a;i++){
            for(int j=0;j<b;j++){
                int sum=A[i]+B[j];
                if(mp1.count(sum)){
                    mp1[sum]+=1;
                }else{
                    mp1[sum]=1;
                }
            }
        }

        for(int i=0;i<c;i++){
            for(int j=0;j<d;j++){
                int sum=-(C[i]+D[j]);
                if(mp1.count(sum)){
                    res+=mp1[sum];
                }
            }
        }
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n^2)
-   空间复杂度：O(1)
