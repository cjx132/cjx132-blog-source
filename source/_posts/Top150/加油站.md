# 综述

**经典的贪心问题**

首先按照暴力的思路枚举每一个作为起点，看是否能够走n步==>时间复杂度O(n^2)

思考如何优化：如果从i走到j，在j处失败了–>==说明走到区间\[i,j-1\]时，油的余量是大于0的（也就是说在这个区间内是有遗产的）==–>那么如果起点在\[i,j\]之间都将失败–>下一次枚举起点直接从i=i+j+1开始–>时间复杂度O(n)

# Code

```java
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n=gas.size();
        for(int i=0,j;i<n;i+=j+1){//枚举每个起点；i+=j+1是优化的关键
            int gas_left=0;
            for(j=0;j<n;j++){//要走n步
                int k=(i+j)%n;
                gas_left+=gas[k]-cost[k];
                if(gas_left<0)break;
            }
            if(j>=n)return i;
        }
        return -1;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
