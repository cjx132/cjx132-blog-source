如何手写一个堆?

1.  插入一个数　　　　　`heap[ ++ cnt] = x; up(cnt);`
2.  求集合当中的最小值　`heap[1];`
3.  删除最小值　　　　　`swap(heap[1],heap[cnt]); cnt -- ; down(1);`
4.  删除任意一个元素　　`swap(heap[k],heap[cnt]); cnt -- ; down(k); up(k);`
5.  修改任意一个元素　　`heap[k] = x; down(k); up(k);`

```c++
// h[N]存储堆中的值, h[1]是堆顶，x的左儿子是2x, 右儿子是2x + 1
// ph[k]=x表示第k个元素在堆中的x索引处
// hp[x]=k表示堆中索引为x的地方存储的是第k个元素
int h[N], ph[N], hp[N], cnt;

// 交换两个点，及其映射关系
void heap_swap(int a, int b)
{
    swap(ph[hp[a]],ph[hp[b]]);
    swap(hp[a], hp[b]);
    swap(h[a], h[b]);
}

void down(int u)
{
    int t = u;
    if (u * 2 <= cnt && h[u * 2] < h[t]) t = u * 2;
    if (u * 2 + 1 <= cnt && h[u * 2 + 1] < h[t]) t = u * 2 + 1;
    if (u != t)
    {
        heap_swap(u, t);
        down(t);
    }
}

void up(int u)
{
    while (u / 2 && h[u] < h[u / 2])
    {
        heap_swap(u, u / 2);
        u >>= 1;
    }
}

// O(n)建堆
//堆是完全二叉树，完全二叉树中有i/2个非叶子节点，且必须从下往上down
//进行down(i)时需要保证i的左右两个儿子都已经满足堆的性质。从n / 2开始向前做，相当于从整棵二叉树的最后一层开始往上做，那么是可以保证这个性质的。但是如果从根节点向下做，则第一次就不满足这个性质了
//n / 2是从倒数第二层开始的, 这样做是因为最后一层可以因为是没有子节点而看作是满足堆条件的
for (int i = n / 2; i; i -- ) down(i);
```
