# 综述

设置两个指针，只有当前位置的字符被匹配后才去看下一个

# Code

```c++
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int k=0;
        for(int i=0;i<t.size()&&k<s.size();i++){
            if(s[k]==t[i])k++;
        }
        return k==s.size();
    }
};
```

思考题

1.  `dp[i][j]`表示当前下标i之后的位置中第一次出现字符j+’a’的位置
    
2.  对于 `"abc"` 在 `"ahbgdc"` 上匹配的时候，由于长字符串第一个 `a` 的下一个出现 `a` 的位置为 -1（不出现），会导致一个 bug。进行哨兵处理
    

```c++
class Solution {
public:
    bool isSubsequence(string s, string t) {
        t.insert(t.begin(),' ');//2.哨兵处理
        int n=t.size();
        vector<vector<int> > dp(n,vector<int>(26,0));
        for(char c='a';c<='z';c++){
            int p=-1;
            for(int i=n-1;i>=0;i--){//1.需要倒序
                dp[i][c-'a']=p;
                if(c==t[i])p=i;
            }
        }
        int index = 0;
		for (char c : s) {
			index = dp[index][c - 'a'];
			if (index == -1)
				return false;
		}
		return true;
    }
};
```
