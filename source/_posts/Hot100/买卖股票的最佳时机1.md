# 综述

-   **[股票问题系列全解](https://leetcode-cn.com/circle/article/qiAgHn/)**
-   求解对于某天i来说的最低历史价格，那么状态可以表示为 `dp[i]`，状态转移方程为`dp[i] = min(dp[i-1],prices[i-1])`；
-   对于每天而言的最大利润可以表示为`price[i] - dp[i]`，所有日期里利润最大那一天的利润就是最大的利润；
-   再考虑到对后面的天数而言，前面的天数只有历史最低价有意义，那么可以直接回收dp的空间，所以可以直接写出这样的代码

# Code

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int cur_min=prices[0],res=0;
        for(int i=1;i<prices.size();i++)
        {
            res=max(res,prices[i]-cur_min);
            cur_min=min(cur_min,prices[i]);
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
