# Code

```c++
class Solution {
public:
    bool checkValidString(string s) {
        int left=0, right=0;
        for(int i=0;i<s.size();i++)
        {
            left+=(s[i]==')'?-1:1);
            right+=(s[s.size()-i-1]=='('?-1:1);
            if(left<0||right<0)return false;
        }
        return true;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
