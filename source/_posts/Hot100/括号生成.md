# 综述

卡特兰数：

> 给定n个0和n个1，它们按照某种顺序排成长度为2n的序列，满足任意前缀中0的个数都不少于1的个数的序列的数量为： `Cat(n) = C(2n, n) / (n + 1)`

左括号的个数在序列中一定满足>=右括号的个数

# Code

```c++
class Solution {
public:
    vector<string>res;
    string t;
    vector<string> generateParenthesis(int n) {
        dfs(0,0,n);
        return res;
    }
    //l,r分别代表当前字符串中左括号和右括号的个数
    void dfs(int l,int r,int n)
    {
        if(l==n&&r==n)
        {
            res.push_back(t);
            return;
        }
        if(l<r)return;//剪枝操作
        if(l<n)
        {
            t+='(';
            dfs(l+1,r,n);
            t.pop_back();
        }
        if(r<n)
        {
            t+=')';
            dfs(l,r+1,n);
            t.pop_back();
        }
    }
};
```

# 复杂度分析

-   时间复杂度：`C(2n, n)`
