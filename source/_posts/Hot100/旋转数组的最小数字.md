# 综述

-   ![image-20210210184853231](https://cjx132.github.io/picture-bed/img/image-20210210184853231.png)

**把最右侧相等的元素去掉**，此时区间就满足左边的都大于等于nums\[0\]，右边的都小于nums\[0\]，找到右边第一个小于nums\[0\]的元素即可

注释中的细节需要注意

# Code

```c++
class Solution {
public:
    int findMin(vector<int>& nums) {
        int j=nums.size()-1;
        while(j>0&&nums[0]==nums[j])j--;//这里是j>0,不包含等于
        if(nums[j]>=nums[0])return nums[0];

        int l=0,r=j;
        while(l<r)
        {
            int mid=(l+r)/2;
            if(nums[mid]<nums[0])r=mid;
            else l=mid+1;
        }
        return nums[r];
    }
};
```

# 复杂度分析

时间复杂度：O(logn)，重复元素导致最差时间复杂度是O(n)

空间复杂度：O(1)
