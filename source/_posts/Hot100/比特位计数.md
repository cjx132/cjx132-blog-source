# 综述

-   奇数一定比前一个偶数多1
-   偶数最后一位为0，一定与该偶数除以2相同，除以2相当于右移一位，即将最后的0抹去

# Code

```c++
class Solution {
public:
    vector<int> countBits(int num) {
        vector<int>res(num+1,0);
        for(int i=1;i<=num;i++){
            if(i&1){
                res[i]=res[i-1]+1;
            }
            else{
                res[i]=res[i/2];
            }
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(n)
