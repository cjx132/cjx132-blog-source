# 什么是集合

对象的容器，实现对对象的操作，类似数组功能

与数组的区别:

> 1.  数组长度固定，集合不固定
> 2.  数组可以存储基本类型和引用类型，集合只能存储引用类型（基本类型可通过自动装箱操作变为包装类）

## Collection父接口

特点：代表一组任意类型的对象，无序、无下标、不能重复

### 常用方法

    > 1.  使用增强for（因为无下标）`for(Object object : collection){ }`
    >     
    > 2.  使用迭代器，**（迭代器遍历过程中，不能用collection其他方法 会报并发修改异常）**
    >     
    >     ```java
    >     //haNext(); 有没有下一个元素
    >     //next(); 获取下一个元素
    >     //remove(); 删除当前元素
    >     Iterator it = collection.iterator();
    >     while(it.hasNext()){
    >       String object = (String)it.next(); //强转
    >       // 可以使用it.remove(); 进行移除元素
    >       // collection.remove(); 不能用collection其他方法 会报并发修改异常
    >     }
    >     ```
    >     
    
4.  判断`collection.contains();` `collection.isEmpty();`

# List子接口

特点：有序、有下标、元素可重复

创建集合 `List list=new ArrayList();`

## 常用方法

1.  添加元素 `list.add();`**会对基本类型进行自动装箱**
    
2.  删除元素 可以用索引`list.remove(0)`
    
    当删除数字与索引矛盾时 对数字强转
    
    > 1.  `list.remove((Object) 10)`推荐使用第一种方法
    > 2.  `list.remove(new Integer(10));`**这里可以删除的原因是Integer的缓冲区**
    
3.  遍历元素
    
    > 1.  使用for遍历
    >     
    >     ```java
    >     for(int i = 0; i < lise.size(); i++){
    >       System.out.println(list.get(i)); 
    >     }
    >     ```
    >     
    > 2.  使用增强for（因为无下标）`for(Object o: list){ }`
    >     
    > 3.  使用迭代器
    >     
    >     ```java
    >     //haNext(); 有没有下一个元素
    >     //next(); 获取下一个元素
    >     //remove(); 删除当前元素
    >     Iterator it = list.iterator();
    >     while(it.hasNext()){
    >       String object = (String)it.next(); //强转
    >       // 可以使用it.remove(); 进行移除元素
    >       // list.remove(); 不能用list其他方法 会报并发修改异常
    >     }
    >     ```
    >     
    > 4.  使用列表迭代器 💡（注意和迭代器区别）
    >     
    >     ```java
    >     ListIterator li = list.listIterator();
    >     while(li.hasNext()){
    >       System.out.println(li.nextIndex() + ":" + li.next()); //从前往后遍历
    >     }
    >     
    >     while(li.hasPrevious()){//li刚开始指向末尾
    >       System.out.println(li.previousIndex() + ":" + li.previous()); //从后往前遍历
    >     }
    >     ```
    >     
    
4.  获取 `list.indexOf( );`
    
5.  返回子集合 `sublist(x, y);`

# Set集合

特点：无序、无下标、元素不可重复

方法：全部继承自Collection中的方法

增、删、遍历、判断与collection一致

## HashSet【重点】【元素对象重写hashCode和equals方法】

存储结构：哈希表（数组+链表+红黑树）

**存储过程（重复依据）**

1.  根据hashCode计算保存的位置，如果位置为空，直接保存，若不为空，进行第二步
2.  再执行equals方法，如果equals为true，则认为是重复，否则形成链表

特点**【元素对象重写hashCode和equals方法】；重写之后可保证不能往Set添加进去重复元素。重要**

-   基于HashCode计算元素存放位置
    -   利用31这个质数，减少散列冲突
        -   31提高执行效率 `31 * i = (i << 5) - i` 转为移位操作
    -   当存入元素的哈希码相同时，会调用equals进行确认，如果结果为true，则拒绝后者存入

新建集合 `HashSet<Student> hashSet = new HashSet<Student>();`

添加元素 `hashSet.add( );`

删除元素 `hashSet.remove( );`

遍历操作

1.  增强for `for( type type : hashSet)`

2.  迭代器 `Iterator<Student> it = hashSet.iterator( );`

判断 `hashSet.contains( );` `hashSet.isEmpty();`

## TreeSet【重点】\[见下文：TreeSet实现元素比较重写方法\](### TreeSet实现元素比较重写方法：)

特点

-   基于排列顺序实现元素不重复
-   实现SortedSet接口，对集合元素自动排序
-   **元素对象的类型必须实现Comparable接口（即重写接口里的compareTo方法），指定排序规则**
-   **通过compareTo方法确定是否为重复元素（返回结果为0代表相等）；不必重写hashCode和equals方法**

存储结构：红黑树

创建集合 `TreeSet<String> treeSet = new TreeSet<>()`

添加元素 `treeSet.add();`

删除元素 `treeSet.remove();`

遍历 1. 增强for 2. 迭代器

判断 `treeSet.contains();`

补充：TreeSet集合的使用

### TreeSet实现元素比较重写方法：

> 1.  **元素对象类型实现Comparable接口（即重写接口里的compareTo方法），指定排序规则；通过compareTo方法确定是否为重复元素（返回结果为0代表相等）；不必重写hashCode和equals方法**

# Map

Map接口的特点

1.  用于存储任意键值对（key - value）
2.  键：无序、无下标、不允许重复（唯一）
3.  值：无序、无下标、允许重复

方法：

1.  V put(K key, V value) 将对象存到集合中，关联键值 ，**key重复则覆盖原值**
2.  Object get(Object key) 根据键获得对应的值
3.  Set keySet() 返回所有的Key
4.  Collection values() 返回包含所有值的Collection集合
5.  Set<Map.Entry<K, V>> entrySet() 键值匹配的Set集合

## Map接口的使用

```java
//创建Map集合
Map<String, String> map = new HashMap<>();
// 1. 添加元素
map.put("cn", "中国");
map.put("uk", "英国");
map.put("cn", "zhongguo"); // 会替换第一个 
// 2. 删除
map.remove("uk");
// 3. 遍历
// 3.1 使用KeySet()
//Set<String> keyset = map.keySet(); // 所有Key的set集合
for(String key : map.keyset()){
  sout(key + "---" + map.get(key));
}
// 3.2 使用entrySet()
//Set<Map.Entry<String, String>> entries = map.entrySet();
for(Map.Entry<String, String> entry : map.entries()){
  sout(entry.getKey() + "---" + entry.getValue();
}
```

## HashMap【重点】

存储结构：哈希表（数组+链表+红黑树）

和HashSet的关系：1. HashSet是通过新建一个HashMap实现的；2. HashMap中key值相同时val值会被替换

**key中元素所属类需要重写hashcode和equals方法防止key值重复**

增、删、遍历、判断与上述一致

**源码分析总结【注意下文中的数字】：**

1.  HashMap刚创建时，table是null，size是0，节省空间；当添加第一个元素时，table容量调整为16
2.  当元素个数大于阈值（16\*0.75 = 12）时，会进行扩容，扩容后的大小为原来的2倍，目的是减少调整元素的个数
3.  jdk1.8 当每个链表长度 >8 ，并且数组元素个数 ≥64时，会调整成红黑树，目的是提高效率
4.  jdk1.8 当链表长度 <6 时 调整成链表
5.  jdk1.8 以前，链表时头插入，之后为尾插入

# Collections工具类

概念：集合工具类，定义了除了存取以外的集合常用方法

直接二分查找`int i = Collections.binarySearch(list, x);` 成功返回索引；**list内元素需要有序**

其他方法 ： **copy复制(目标集合与源集合大小要相等)、reverse反转、shuffle打乱、sort排序(可使用匿名内部类重写比较器，定制比较规则)**
