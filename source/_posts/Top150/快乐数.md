# 综述

-   方法：  
    使用 “快慢指针” 思想，找出循环：“快指针” 每次走两步，“慢指针” 每次走一步，当二者相等时，即为一个循环周期。此时，判断是不是因为 1 引起的循环，是的话就是快乐数，否则不是快乐数。
-   不是快乐数的数称为不快乐数（unhappy number），所有不快乐数的数位平方和计算，最後都会进入 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 的循环中；快乐数会进入1的循环

# Code

```c++
class Solution {
public:
    bool isHappy(int n) {
        int fast=n;
        int slow=n;
        do{
            slow=getNum(slow);
            fast=getNum(fast);
            fast=getNum(fast);
        }while(fast!=slow);
        return fast==1;
    }

    int getNum(int n){
        int ans=0;
        while(n>0){
            ans+=(n%10)*(n%10);
            n/=10;
        }
        return ans;
    }
};
```
