# 综述

-   首先对数组排序。
-   固定最长的一条边，运用双指针扫描
-   如果 `nums[l] + nums[r] > nums[i]`，同时说明 `nums[l + 1] + nums[r] > nums[i], ..., nums[r - 1] + nums[r] > nums[i]`，满足的条件的有 r - l 种，r 左移进入下一轮。
-   如果 `nums[l] + nums[r] <= nums[i]`，l 右移进入下一轮。
-   枚举结束后，总和就是答案。

# Code

```c++
class Solution {
public:
    int triangleNumber(vector<int>& nums) {
        int n=nums.size();
        sort(nums.begin(),nums.end());
        int ans=0;
        for(int i=n-1;i>=0;i--)
        {
            int l=0,r=i-1;
            while(l<r)
            {
                if(nums[l]+nums[r]<=nums[i])l++;
                else 
                {
                    ans+=r-l;
                    r--;
                }
            }
        }
        return ans;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n^2)
-   空间复杂度：O(1)
