# 综述

[参考](https://www.acwing.com/solution/content/160/)

`hash[c]`表示的是当前c这个字母还缺多少个，`hash[s[j]] == 0` 表示 `s[j]` 这个字母已经足够了 。

# Code

```c++
class Solution {
public:
    string minWindow(string s, string t) {
        unordered_map<int,int>hash;
        int cnt=0;
        for(auto c:t)
        {
            if(!hash[c])cnt++;
            hash[c]++;
        }
        string res="";
        for(int i=0,j=0,t=0;i<s.size();i++)
        {
            if(hash[s[i]]==1)t++;
            hash[s[i]]--;
            while(hash[s[j]]<0&&t==cnt)
            {
                hash[s[j]]++;
                j++;
            }
            if(t==cnt)
            {
                if(res==""||res.size()>i-j+1)
                    res=s.substr(j,i-j+1);
            }
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(n)
