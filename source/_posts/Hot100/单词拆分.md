# 题目

![](/images/Top100/%E5%8D%95%E8%AF%8D%E6%8B%86%E5%88%86.png)

# 综述

-   dp\[i\]表示字符串s，以下标i开始到最后的字符串是否可被 wordDict 拆分（这里下标i从s.size()-1开始求解，倒着递推）
-   注意substr的用法

# Code

```c++
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string>m(wordDict.begin(),wordDict.end());
        int len=s.size();
        vector<int>dp(len+5,0);
        //dp[i]表示字符串s，以下标i开始到最后的字符串是否可被 wordDict 拆分
        dp[s.size()]=1;//初始化
        for(int i=s.size()-1;i>=0;i--){//倒着求dp[i]的值
            for(int j=s.size();j>i;j--){
                //关于j的取值范围，需要仔细推敲；可以结合特殊样例分析，比如想想如何求解dp[s.size()-1]
                if(dp[j]&&m.count(s.substr(i,j-i))){//字符串s[i,j-1]在字典中，且 dp[j]为真，所以此时dp[i]为真
                    dp[i]=true;
                    break;//重要，找到之后就可以跳出了
                }
            }
        }
        return dp[0];//dp[0]的结果代表整个字符串是否满足结果
    }
};
```

# 复杂度分析

时间复杂度：O(n^2)

空间复杂度：O(n)
