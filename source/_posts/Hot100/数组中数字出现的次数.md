# 综述

-   异或的性质
    
    > 同一位的数字相同则为 0，不同则为 1
    
-   异或的规律
    
    > 任何数和本身异或则为0
    > 
    > 任何数和 0 异或是他本身
    > 
    > 异或满足交换律：17 xor 19 xor 17 相当于 17 xor 17 xor 19 = 0 xor 19 = 19
    
-   详解
    
    > [https://leetcode-cn.com/problems/shu-zu-zhong-shu-zi-chu-xian-de-ci-shu-lcof/solution/zhi-chu-xian-yi-ci-de-shu-xi-lie-wei-yun-suan-by-a/](https://leetcode-cn.com/problems/shu-zu-zhong-shu-zi-chu-xian-de-ci-shu-lcof/solution/zhi-chu-xian-yi-ci-de-shu-xi-lie-wei-yun-suan-by-a/)
    
-   一定要加括号，&的优先级比==低
    

关于本题：

第一次遍历得到的是 这两个只出现一次的数字（分别用a,b表示） 异或的结果（用变量t表示）。下面思考，如何把这两个数分开？

> 1.  考虑异或的性质：同一位的数字相同则为 0，不同则为 1。因此，我们可以找到t中第一个是1的位置，就说明在这一位置上，a和b不一样
> 2.  利用1中提出的方法，我们就可以把a和b分开分到不同的组中，具体看代码就可以理解

# Code

```c++
class Solution {
public:
    vector<int> singleNumbers(vector<int>& nums) {
        vector<int>res;
        int t=0;
        int n=nums.size();
        for(int i=0;i<n;i++){
            t^=nums[i];
        }
        int h=1;
        while((h&t)==0){//找到t第一个是1位置(一定要加括号，&的优先级比==低)
            h<<=1;
        }
        int a=0;
        int b=0;
        for(int i=0;i<n;i++){
            if((nums[i]&h)==0){//(一定要加括号，&的优先级比==低)
                a^=nums[i];
            }
            else{
                b^=nums[i];
            }
        }
        res.push_back(a);
        res.push_back(b);
        return res;
    }
};
```
