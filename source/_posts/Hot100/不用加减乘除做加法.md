# 综述

a + b 的问题拆分为 (a 和 b 的无进位结果) + (a 和 b 的进位结果)

1.  无进位加法使用异或运算计算得出
2.  进位结果使用与运算和移位运算计算得出
3.  循环此过程，直到进位为 0

a,b异或得到无进位之和，(a&b)<<1得到进位的和；二者相加就是最终答案

# Code

```c++
class Solution {
public:
    // int add(int a, int b) {
    //     int na=(unsigned int)(a&b)<<1;//进位之和
    //     int nb=a^b;//无进位求和
    //     if(na==0)return nb;//进位为0则得到最终答案为nb;
    //     return add(na,nb);
    // }
    int add(int a, int b) {
        while(b){
            int tmp=a^b;//无进位求和
            b=(unsigned int)(a&b)<<1;//进位之和
            a=tmp;
        }
        return a;
    }
};
```
