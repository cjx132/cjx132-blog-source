# 综述

-   **经典**区间排序的贪心问题
-   先对右边界按照递增顺序排序
-   每次选择点的时候贪心的选择区间的右端点，如果一个区间的左端点严格大于当前的右端点，那么结果+1

# Code

```c++
bool cmp(vector<int>& a,vector<int>& b){
    return a[1]<b[1];
}
class Solution {
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        sort(points.begin(),points.end(),cmp);
        int res=0,r=INT_MIN;
        if(points.size()>0&&points[0][0]==INT_MIN)res++;//特判
        for(auto p:points){
            if(p[0]>r){//当前区间左端点严格大于r
                res++;
                r=p[1];//更新右端点
            }
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
