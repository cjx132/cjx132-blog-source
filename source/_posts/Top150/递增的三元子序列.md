# 题目

![image-20201125120043299](https://cjx132.github.io/picture-bed/img/image-20201125120043299.png)

# 综述

-   使用双指针：f保存遍历过程中的最小数，s保存遍历过程中的第二小数。
-   if–else if–else的结构保证f保存的最小数的下标<s保存的第二小数的下标<最大数的下标（此时返回true即可）
-   细节：if中的判断必须包含=（使用测试样例\[1,1,1,1\]测试即可）

# Code

```c++
class Solution {
public:
    bool increasingTriplet(vector<int>& nums) {
        int f=INT_MAX;
        int s=INT_MAX;

        for(int num:nums){
            if(num<=f){//必须要有等号
                f=num;//f中保存最小的
            }else if(num<=s){//必须要有等号
                s=num;//s中保存第二小的
            }else{
                return true;
            }
        }
        return false;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
