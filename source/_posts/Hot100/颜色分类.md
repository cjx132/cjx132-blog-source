# 综述

-   参考**快排全解**这篇笔记
    
-   partation的结果是：**【partitation结果区间需牢记】**
    

> 1.  less than, arr\[low…lt\] < temp，初始状态为空
> 2.  greater than, arr\[gt…high\] > temp，初始状态为空;
> 3.  arr\[lt+1…i) == temp

-   lt与gt的初始值须注意

# Code

```c++
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int len=nums.size();
        int lt=-1;
        int gt=len;
        int i=0;
        while(i<gt){
            if(nums[i]==1){
                ++i;
            }else if(nums[i]==2){
                swap(nums[i],nums[--gt]);
            }else{
                swap(nums[i++],nums[++lt]);
            }
        }
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
