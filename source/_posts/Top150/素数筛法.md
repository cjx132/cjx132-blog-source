# Code

```c++
class Solution {
public:
    int ans=0;
    int countPrimes(int n) {
        vector<int>v(n,0);
        for(int i=2;i*i<n;i++){//因子的对称性,sqrt(n)即为结束条件
            if(v[i]==0){//v[i]为0代表素数
                for(int j=i*i;j<n;j+=i){//不用从2*i开始计算,存在大量的冗余
                    v[j]=1;
                }
            }
        }
        for(int i=2;i<n;i++){
            if(v[i]==0)ans++;
        }
        return ans;
    }
};
```

# 复杂度分析

-   时间复杂度：O (N\*loglogN))
-   空间复杂度：O(n)
