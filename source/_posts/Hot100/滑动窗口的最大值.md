# 综述

[https://leetcode-cn.com/problems/sliding-window-maximum/solution/dan-diao-dui-lie-by-labuladong/](https://leetcode-cn.com/problems/sliding-window-maximum/solution/dan-diao-dui-lie-by-labuladong/)

-   双端队列:头部尾部都能插入删除
    
-   单调队列:「单调队列」的核心思路和「单调栈」类似。单调队列的 push 方法依然在队尾添加元素，但是要把前面比新元素小的元素都删掉：这样就能**维护一个单调递减的队列，就能保证每次取队列头部的值即能得到当前窗口的最大值。**

-   细节处理见注释部分
    

# Code

```c++
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int> &nums, int k) {
        vector<int> res;
        deque<pair<int, int>> mq;
        for (int i = 0; i < nums.size(); i++) {
            while (!mq.empty() && mq.back().second <= nums[i])mq.pop_back();
            mq.push_back(pair<int, int>(i, nums[i]));
            while (!mq.empty() && mq.front().first < i + 1 - k)mq.pop_front();
            //本题特殊处理一下，前k-1个结果不要
            if (i + 1 >= k)res.push_back(mq.front().second);
        }
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
    > 单独看 push 操作的复杂度确实不是 O(1)，但是算法整体的复杂度依然是 O(N)线性时间。要这样想，nums 中的每个元素最多被 push\_back 和 pop\_back 一次，没有任何多余操作，所以整体的复杂度还是 O(N)。
    
-   空间复杂度：O(k)
