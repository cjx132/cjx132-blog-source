# Code

```c++
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_map<int,int>tr_left,tr_right;
        int res=0;
        for(auto x:nums)
        {
            int left=tr_right[x-1];
            int right=tr_left[x+1];
            tr_left[x-left]=max(tr_left[x-left],left+right+1);
            tr_right[x+right]=max(tr_right[x+right],left+right+1);
            res=max(res,left+right+1);
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(n)
