# Code

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int len=prices.size();
        int un_hold=0;
        int hold=-prices[0];
        for(int i=1;i<len;i++){
            un_hold=max(un_hold,hold+prices[i]);
            hold=max(hold,un_hold-prices[i]);
        }
        return un_hold;
    }
};
```

**贪心解法：只要有爬坡就算进去**

```c++
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int res=0;
        for(int i=1;i<prices.size();i++)
            res+=max(0,prices[i]-prices[i-1]);
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
-   空间复杂度：O(1)
