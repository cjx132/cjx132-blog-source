# 综述

使用的循环是while(1)，每走一轮，快指针比慢指针多走一步，最终一定会追上

# Code

```c++
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode *a=head,*b=head;
        while(1)
        {
            if(!b||!b->next)return false;
            a=a->next;
            b=b->next->next;
            if(a==b)return true;
        }
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
