# 题目

![](/images/Top100/%E7%9B%AE%E6%A0%87%E5%92%8C.png)

# 综述

-   先排出现次数最多的，以n+1为周期，细节见代码注释

# Code

```c++
class Solution {
public:
    int leastInterval(vector<char>& tasks, int n) {
        int len=tasks.size();
        int map[26]={0};
        for(int i=0;i<len;i++){
            map[tasks[i]-'A']++;
        }
        int time=0;
        sort(map,map+26);
        while(map[25]>0){//结束的条件是所有任务全部排好
            for(int i=0;i<n+1;i++){//n+1为周期进行任务排列,先排任务数最多的种类
                //这句代码非常重要，不能缺少。（map[25]==0说明此种任务已经排完，后续不会出现此种任务导致排列不合法，因此，跳出本层循环，开启新一轮n+1）如果缺少这段代码，可能导致最终结果偏大，因为后面可能map值都是0，但还是要走完n+1
                if(map[25]==0)break;
                if(i<26&&map[25-i]>0){
                    map[25-i]--;
                }
                time++;
            }
            sort(map,map+26);
        } 
        return time;
    }
};
```

# 复杂度分析

时间复杂度：O(time)

空间复杂度：O(1)
