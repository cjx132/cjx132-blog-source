**从两头往里移动，向内移动短板才有可能使得总面积增大，不断更新最大值**

# Code

```c++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int len=height.size();
        int i=0;
        int j=len-1;
        int res=0;
        while(i<j){
            height[i]<height[j]?
            res=max(res,(j-i)*height[i++]):
            res=max(res,(j-i)*height[j--]);
        }
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
