# 综述

-   **抽屉原理**
-   利用抽屉原理对数字`[1,n]`进行二分，**而不是对数组下标进行二分**

# Code

```c++
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int l=1;int r=nums.size()-1;
        while(l<r)
        {
            int mid=l + r >>1;//[l,mid],[mid+1,r]

            int s=0;
            for(int x:nums)s+=x>=l&&x<=mid;
            if(s>mid-l+1)r=mid;//说明左边区间的数比范围要大，下次在这里进行搜索
            else l=mid+1;
        }
        return l;
    }
};
```

# 复杂度分析

时间复杂度：O(nlogn)

空间复杂度：O(1)
