# 综述

关键是对每个字符串计算哈希值，哈希函数的实现

这里的哈希值是类似`"2a3b..."`的字符串

# Code

```c++
class Solution {
public:
    string hash(string &str)
    {
        string res;
        int q[26]={0};
        for(char c:str)
            q[c-'a']++;
        for(int i=0;i<26;i++)
            if(q[i])
            {
                string t;
                t.push_back(q[i]+'0'),t.push_back(i+'a');//"2a3b..."
                res+=t;
            }
        return res;
    }
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string,vector<string>>h;
        for(auto str:strs)
        {
            string t=hash(str);
            h[t].push_back(str);
        }
        vector<vector<string>>ans;

        for(auto item:h)
            ans.push_back(item.second);
        return ans;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(n)
