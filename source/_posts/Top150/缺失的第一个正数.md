# 综述

-   原地哈希题目的特征：**通过原地哈希之后，我们可以容易的求解我们所要找的答案，通常数组中的元素值有特殊要求：如在某个区间内。或者最终的答案在某个区间内。**
    
-   分析题意可知：最小的正整数为1，答案一定在\[1,n+1\]区间内。其中n为数组长度。
    
    > 1.  首先对数组中元素原地哈希，哈希关系为f(i)=i+1。如把数组中元素值为1的元素放在数组的第一个位置。
    > 2.  当数组中的元素类似于\[1,2,3\]这种时，答案为n+1；
    > 3.  当数组中元素为其他情况时，答案是原地哈希之后，第一个不满足哈希关系的下标值+1。看代码即可理解
    
-   此题可看做原地哈希的模板题：**重点理解代码中的注释以及复杂度分析内容。**
    

# Code

```c++
class Solution {
public:
    int firstMissingPositive(vector<int>& nums) {
        int n=nums.size();
        for(int i=0;i<n;i++){//把下标i想成一个一个的抽屉，抽屉i中放的数必须和i相等
            
            //接下来，我们要做的事：判断一个数是不是放在了正确的抽屉里，如果不是，就把这个数放在正确的抽屉里
            

           //我们要判断nums[i]是否放对了抽屉：当前判断的数是nums[i],当前的抽屉是i
            
            while(i+1!=nums[i]){//说明现在判断的这个数，放错了抽屉，不应该在这里；现在判断的这个数应该放在下标为nums[i]-1的抽屉里
                if(nums[i]>n||nums[i]<1||nums[i]==nums[nums[i]-1])break;//如果下标nums[i]-1越界，跳出循环（这样写避免int溢出）;如果下标为nums[i]-1的抽屉里已经放着同样的数，那么满足哈希条件，本次循环结束（这里的判断条件一定不能写错）
                swap(nums[i],nums[nums[i]-1]);//把这个数放在正确的抽屉里，同时，我们还要循环判断被交换过来的数是不是放在了正确的地方，回到上面的循环
            }
        }
        for(int i=0;i<n;i++){
            if(i+1!=nums[i]){
                return i+1;
            }
        }
        return n+1;
    }
};
```

# 复杂度分析

-   时间复杂度：O(N)，这里 N 是数组的长度。虽然 for 循环里面套了 while，但是每一个数来到它应该在的位置以后，位置就不会再变化。这里用到的是均摊复杂度分析的方法：如果在某一个位置 while 循环体执行的次数较多，那么一定在后面的几个位置，根本不会执行 while 循环体内的代码，也就是说最坏的情况不会一直出现。
    
-   空间复杂度：O(1)
