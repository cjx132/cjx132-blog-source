# 综述

树的后继就是中序遍历下的下一个节点

-   1.  当前节点有右子树时，后继就是右子树的最左边的节点
    2.  否则，如果当前节点是其父节点的左节点，那么父节点就是当前节点的后继。如果不是这种情况就一直寻找当前节点的父节点，直到满足这一结果

# Code

```c++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode *father;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL), father(NULL) {}
 * };
 */
class Solution {
public:
    TreeNode* inorderSuccessor(TreeNode* p) {
        if(!p)return nullptr;
        if(p->right)
        {
            p=p->right;
            while(p->left)
                p=p->left;
            return p;
        }
        else
        {
            while(p->father&&p==p->father->right)
                p=p->father;
            
            return p->father;
        }
    }
};
```

# 复杂度分析

时间复杂度：O(h)：h是树的高度
