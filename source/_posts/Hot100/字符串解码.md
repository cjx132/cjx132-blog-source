# 综述

这题看到括号的匹配，首先应该想到的就是用栈来解决问题。

其次，读完题目，要我们类似于制作一个能使用分配律的计算器。想象：如3\[a2\[c\]b\] 使用一次分配律-> 3\[accb\] 再使用一次分配律->accbaccbaccb

# Code

```c++
class Solution {
public:
    string decodeString(string s) {
        stack<int>si;
        stack<string>ss;
        int n=s.size();
        int num=0;
        string res;
        for(int i=0;i<n;i++)
        {
            if(isdigit(s[i]))num=num*10+s[i]-'0';
            else if((s[i]>='a'&&s[i]<='z')||(s[i]>='A'&&s[i]<='Z'))
                res+=s[i];
            else if(s[i]=='[')//将‘[’前的数字压入数字栈内， 字母字符串压入字符串栈内，之后置空
            {
                si.push(num);
                ss.push(res);
                num=0;
                res="";
            }
            else if(s[i]==']')//遇到‘]’时，操作与之相配的‘[’之间的字符，使用分配律
            {
                int t=si.top();
                si.pop();
                while(t--)ss.top()+=res;//t个res追加到后面
                //这里必须进行赋值，本次更新结果作为新的res值，可能后续压入栈中
                //之后若还是字母，就会直接加到res之后，因为它们是同一级的运算
                //若是左括号，res会被压入strs栈，作为上一层的运算
                res=ss.top();
                ss.pop();
            }
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(n)
