# 综述

字符不一定有序，不是统计字符，而是压缩字符串

如果统计字符的话，是需要排序的

# Code

```c++
class Solution {
public:
    int compress(vector<char>& chars) {
        int n=chars.size();
        if(n<2)return n;

        int j=0;
        int first=0;//记录每个字符第一次出现的位置
        for(int i=1;i<=n;i++)//i==n时需要计算最后一个字符的长度
        {
            if(i==n||chars[i]!=chars[i-1])
            {
                int len=i-first;
                if(len>1)
                    for(auto c:to_string(len))
                        chars[++j]=c;
                
                if(i==n)break;//i==n时只需计算长度即可
                chars[++j]=chars[i];
                first=i;
            }
        }
        return ++j;
    }
};
```
