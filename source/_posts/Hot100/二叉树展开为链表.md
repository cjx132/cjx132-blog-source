# 综述

[参考](https://www.acwing.com/solution/content/202/)

p是当前节点左子树的最右节点

1.  当前节点右子树接在p的后面
2.  将当前节点左子树接在当前节点的右节点
3.  当前节点左子树为空

由于当前节点左子树为空,当前节点右移

# Code

```c++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void flatten(TreeNode* root) {
        TreeNode *cur=root;
        while(cur)
        {
            if(cur->left)
            {
                TreeNode *p=cur->left;
                while(p->right)p=p->right;
                //p是当前节点左子树的最右节点
                p->right=cur->right;//1.当前节点右子树接在p的后面
                cur->right=cur->left;//2.将当前节点左子树接在当前节点的右节点
                cur->left=nullptr;//3.当前节点左子树为空
            }
            cur=cur->right;//由于当前节点左子树为空,当前节点右移
        }
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)，其中n是二叉树的节点数。
-   空间复杂度：O(1)
