# 综述

-   dp\[i\]表示兑换总钱数为i时所需要的最小硬币数
-   dp\[i\]等于M时，代表无解
-   在所有的选择中选择最小值

# Code

```c++
class Solution {
public:
    int f[10010];
    int coinChange(vector<int>& coins, int amount) {
        memset(f,0x3f,sizeof f);
        f[0]=0;
        for(int i=1;i<=amount;i++)
            for(int j=0;j<coins.size();j++)
                if(i>=coins[j])
                    f[i]=min(f[i],f[i-coins[j]]+1);
        
        return f[amount]==0x3f3f3f3f?-1:f[amount];
    }
};
```
