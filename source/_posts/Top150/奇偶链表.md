# 题目

![image-20201122172147821](https://cjx132.github.io/picture-bed/img/image-20201122172147821.png)

# 综述

-   分别定义奇偶链表；
    
-   遍历原链表，将当前结点交替插入到奇链表和偶链表（尾插法）；
    
-   将偶链表拼接在奇链表后面。
    

# Code

```c++
class Solution {
public:
    ListNode* oddEvenList(ListNode* head) {
        // 分别定义奇偶链表的 虚拟头结点 和 尾结点
        ListNode* dummy1=new ListNode();
        ListNode* dummy2=new ListNode();

        ListNode* oddTail=dummy1;
        ListNode* evenTail=dummy2;

        ListNode* cur=head;
        // 遍历原链表，根据 isOdd 标识位决定将当前结点插入到奇链表还是偶链表（尾插法）
        bool isOdd=true;
        while(cur){
            if(isOdd){
                oddTail->next=cur;
                oddTail=oddTail->next;
            }else{
                evenTail->next=cur;
                evenTail=evenTail->next;
            }
            isOdd=!isOdd;
            cur=cur->next;
        }
        // 将奇链表后面拼接上偶链表，并将偶链表的next设置为null
        evenTail->next=nullptr;
        oddTail->next=dummy2->next;
        return dummy1->next;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
