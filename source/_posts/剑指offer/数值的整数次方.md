# 综述

-   **不使用位运算即可不用特判**

# Code

```c++
class Solution {
public:
    double myPow(double x, int n) {
        int t=n;
        double res=1;
        while(n)
        {
            if(n%2)res=res*x;
            n/=2;
            x=x*x;
        }
        return t<0?1/res:res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(logn)
-   空间复杂度：O(1)
