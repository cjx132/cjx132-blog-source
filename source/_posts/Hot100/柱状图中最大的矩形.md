# 综述

[官方题解视频讲解很清楚，重点看栈的模拟解释部分](https://leetcode-cn.com/problems/largest-rectangle-in-histogram/solution/zhu-zhuang-tu-zhong-zui-da-de-ju-xing-by-leetcode-/)

**哨兵技巧**：头尾各插入一个-1的值，保证一定可以找到左右两边小于当前数的值

以当前柱子 i 的高度作为矩形的高，那么矩形的宽度边界即为向左找到第一个高度小于当前柱体 i 的柱体，向右找到第一个高度小于当前柱体 i 的柱体。中间的（不包括边界）就是矩形的宽度，高度就是当前柱子 i 的高度

**对于每个元素，找其左右两边第一个小于当前元素的下标，和接雨水相反**

**当前元素（栈顶元素t），左边第一个小于当前元素的下标（栈顶下面的元素），右边第一个小于当前元素的下标（height\[i\]），三者形成雨水**

# Code

```c++
class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int n=heights.size();
        stack<int>stk;
        //左右边界值
        heights.insert(heights.begin(),-1);
        heights.push_back(-1);
        int res=0;
        for(int i=0;i<heights.size();i++)
        {
            while(!stk.empty()&&heights[i]<heights[stk.top()])
            {
                int t=stk.top();
                stk.pop();
                while(!stk.empty()&&heights[stk.top()]==heights[t])
                    stk.pop();
                if(!stk.empty())
                    res=max(res,(i-stk.top()-1)*heights[t]);
            }
            stk.push(i);
        }
        return res;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
    
-   空间复杂度：O(n)
