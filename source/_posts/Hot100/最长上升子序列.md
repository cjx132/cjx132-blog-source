# 综述

-   **子序列是不一定连续的，子串是连续的**
-   最长上升子序列模型需要牢记

# Code

`tail[i]`表示长度为i的最长上升子序列，这个子序列最后一个数的值。因此，这个值越小越好，tail数组下标的范围是\[1，n\]。这个数组的长度就是本题的答案

如何构造这个数组：

对于原数组中每一个数`nums[i]`，我要把它放在tail数组合适的位置。假设j是tail数组中最后一个小于`nums[i]`的位置，我们应该把nums\[i\]放在`tails[j+1]`的位置，同时不断更新tail数组的长度

```c++
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int res=0;
        int n=nums.size();
        if(n==0)return res;
        vector<int>tail(n+1,0);
        for(int i=0;i<nums.size();i++){
            int l=0,r=res;
            while(l<r){//在tail数组中二分找到最后一个小于nums[i]的位置
                int mid=(l+r+1)>>1;
                if(tail[mid]<nums[i])l=mid;
                else r=mid-1;
            }
            tail[l+1]=nums[i];
            res=max(res,l+1);//维护tail数组的最大长度
        }
        return res;
    }
};
```

**以第i个数结尾的上升子序列**

```c++
class Solution {
public:
    
    int lengthOfLIS(vector<int>& nums) {
        int n=nums.size();
        int res=0;
        vector<int>f(n,0);
        for(int i=0;i<n;i++)
        {
            f[i]=1;//这里必须先取1
            for(int j=0;j<i;j++)
                if(nums[i]>nums[j])
                    f[i]=max(f[i],f[j]+1);
            res=max(res,f[i]);//在这里找最大值
        }
        return res;
    }
};
```

# 复杂度分析

时间复杂度：O(nlogn)

空间复杂度：O(n)
