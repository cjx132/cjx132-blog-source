# 综述

-   一些数学知识：
    1.  无理数不能用分数形式表示。即用分数表示的包含两种：1.有限小数；2.无限循环小数
    2.  模拟小学数学的除法，当第二次出现相同的余数时，说明：1. 小数存在循环；2. 且第一轮循环结束了；3.这个余数第一次出现的位置，就是循环开始的位置
    3.  本题中写完上述代码，需要考虑：1. 正负数问题；2. 整数越界问题
-   代码细节参考以下注释：清晰易懂

# Code

```java
class Solution {
public:
    string fractionToDecimal(int numerator, int denominator) {
        if(numerator==0)return "0";
        string ans;
        if((numerator>0)^(denominator>0))ans+="-";
        long long num =(long long) numerator;
        long long den=(long long) denominator;
        num=llabs(num),den=llabs(den);
        unordered_map<int,int>h;

        ans+=to_string(num/den);
        num%=den;
        if(num==0)return ans;
        ans+=".";
        int index=ans.size()-1;
        while(num&&h.count(num)==0)//余数不为0且余数没有第二次出现
        {
            h[num]=++index;
            num*=10;
            ans+=to_string(num/den);
            num%=den;
        }
        if(h.count(num))
        {
            ans.insert(h[num],"(");
            ans+=")";
        }
        return ans;
    }
};
```
