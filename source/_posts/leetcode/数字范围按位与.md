# 综述

主要的想法是统计两个数二进制表示的公共前缀。

因为假设两个数在第i位前面都相同，第i位一个为零，一个为一，那么这两个数之间一定存在一个数，这个数得第i位为1，且后面的都是零。这样与之后i位以及之后就都是零了。

所以求两个数的公共前缀即可。 通过两个数不断右移，直到两个数相等。在左移对应的位数。  
[参考](https://leetcode-cn.com/problems/bitwise-and-of-numbers-range/solution/er-jin-zhi-biao-shi-gong-gong-qian-zhui-by-acw_wan/)

# Code

```c++
class Solution {
public:
    int rangeBitwiseAnd(int m, int n) {
        int cnt=0;
        while(m!=n){
            m>>=1;
            n>>=1;
            cnt++;
        }
        return m<<cnt;
    }
};
```
