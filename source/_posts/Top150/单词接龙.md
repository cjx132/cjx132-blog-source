# 综述

-   bfs中注意的两个问题
    1.  需要定义标记数组，在每次扩散进入队列之后，还要在标记数组中标记**（标记数组的含义是标记是否入过队列，标记数组的更新紧跟入队操作之后）**
    2.  如果需要统计层次数，那么在while循环中需要以每层为单位弹出队列
-   无向图中两个顶点之间的最短路径的长度，可以通过广度优先遍历得到；
-   为什么 BFS 得到的路径最短？可以把起点和终点所在的路径拉直来看，两点之间线段最短；
-   **已知目标顶点的情况下**，可以分别从起点和目标顶点（终点）执行广度优先遍历，直到遍历的部分有交集，这是双向广度优先遍历的思想。

* * *

**关于双向广度优先遍历必须要注意两个问题**

[双向bfs的实现参考](https://labuladong.gitbook.io/algo/di-ling-zhang-bi-du-xi-lie/bfs-kuang-jia)

1.  双向广度优先遍历的标记数组和单路的不同：**在双路中标记数组的含义是：标记是否被访问过**（体现在代码中就是visit数组的位置不同，仔细看代码中的注释，**访问时才更新**）
    
2.  当字典中不存在目标单词时，**必须进行特判**，双向bfs不能保证这种情况下可以得到正确结果
    
3.  关于visit数组的含义：在算法笔记中的解释如下：如果把visit数组的含义设置成是否已被访问：有可能在某个节点正在队列中（但是还没被访问）时由于其他节点可以到达它而将这个节点再次入队。
    
    > 因此，双向bfs设置为是否被访问过，可以使得某个节点可以重复入队，这样才能两个集合找到交集（满足条件时的返回）。如果设置成是否已入过队列，那么一个节点不可能入两次队列，在双向bfs中，永远也找不到答案，返回结果永远都是0。
    

# Code

单向bfs

```c++
class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string>wordSet(wordList.begin(),wordList.end());//字典存入set，加快查找速度
        unordered_set<string>visit;
        queue<string>qb;
        qb.push(beginWord);
        visit.insert(beginWord);
        int ans=0;
        while(!qb.empty()){
            int n=qb.size();
            ans++;//层数+1
            for(int k=0;k<n;k++){//一次遍历一层
                string top=qb.front();
                qb.pop();
                if(top==endWord)return ans;
                for(int i=0;i<top.size();i++){
                    string str=top;//不可少，保证每次都是基于top的值修改
                    for(int j=0;j<26;j++){
                        str[i]=j+'a';
                        if(wordSet.count(str)!=0&&visit.count(str)==0){
                            qb.push(str);
                            visit.insert(str);//加入队列之后，还要对其进行标记
                        }
                    }
                }
            }  
        }
        return 0;
    }
};
```

双向bfs

```c++
class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string>wordSet(wordList.begin(),wordList.end());//字典存入set，加快查找速度
        unordered_set<string>visit;//标记数组，标记是否已被访问

        unordered_set<string>q1;//从前往后扩散时，每层保存的节点
        unordered_set<string>q2;//从后往前扩散时，每层保存的节点

        //注意点1：必须进行特判，因为从两端往中间扩散时，可能会存在这种情况：
        //endWord根本不在字典中，在往前扩散时，可能会存在公共交集的情况
        if(wordSet.count(endWord)==0){
            return 0;
        }

        q1.insert(beginWord);
        q2.insert(endWord);
        int ans=0;
        while(!q1.empty()){
            ans++;//层数+1
            unordered_set<string>temp;

            for(auto eachstr:q1){//一次遍历一层
                visit.insert(eachstr);//注意点2：visit数组更新的位置，访问时更新
                if(q2.count(eachstr)!=0)return ans;//存在交集，满足条件即可返回
                
                for(int i=0;i<eachstr.size();i++){
                    string str=eachstr;//不可少，保证每次都是基于eachstr的值修改
                    for(int j=0;j<26;j++){
                        str[i]=j+'a';
                        if(wordSet.count(str)!=0&&visit.count(str)==0){
                            temp.insert(str);
                            //和单源bfs不同，绝对不能在这里更新visit
                        }  
                    }
                }
            }
            //正常情况下，下次访问q2
            q1=q2;
            q2=temp;

            //优化：从集合元素少的扩散
            if(q1.size()>q2.size()){
                swap(q1,q2);
            }
        }
        return 0;
    }
};
```
