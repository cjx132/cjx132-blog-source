# 综述

`f[n]`表示有n个人时最终胜利者的编号

第一轮:`f[n]`  
淘汰的编号是m-1,之后重新编号,有以下关系  
①x->(x-m+n)%(n-1);

第二轮`f[n-1]`  
根据①==>(`f[n]`\-m+n)%(n-1)=`f[n-1]`  
\==>递推关系:`f[n]`\=(`f[n-1]`+m)%(n-1)

初始情况:`f[1]`\=0;

# Code

```c++
class Solution {
public:
    int lastRemaining(int n, int m) {
        // queue<int>q;
        // for(int i=0;i<n;i++)q.push(i);
        // while(q.size()>1){
        //     for(int i=0;i<m-1;i++){
        //         q.push(q.front());
        //         q.pop();
        //     }
        //     // return q.front();
        //     q.pop();
        // }
        // return q.front();
        int p=0;//i=1时，最终胜利者的（位置）下标
        for(int i=2;i<=n;i++){//i代表此时队列里还有多少人
            p=(p+m)%i;
            //在剔除一个人后，胜利者的位置会前移m（下标-3），所以倒过来胜利者的位置后移（下标+3），防止超过队列长度取模
        }
        return p;
    }
};
```
