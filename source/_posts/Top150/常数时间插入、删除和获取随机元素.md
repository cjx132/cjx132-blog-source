# 综述

-   首先，要在O(1)时间内的删除指定值的元素，肯定要利用哈希表的。但是问题在于随机返回一个元素，无序容器的迭代器不支持随机访问。而显然，支持随机访问的迭代器必须是管理连续内存的容器，常见的有vector 、deque等
    
    所以这里，用vector存储每一个插入的元素，哈希表存储插入元素的下标。这样问题的关键就不是插入了，而是删除：怎样做到O(1)时间从vector容器内删除元素呢?显然，要从vector容器内删除元素，只能从其尾部删除。所以方法是:先交换vector队尾元素和待删除元素的值(因为哈希表中存储了下标，所以可以直接得到待删除元素的下标)，然后把队尾元素删除，并更新原队尾元素的下标即可，其他位置的元素下标并没有变化。
    
    [参考题解](https://leetcode-cn.com/problems/insert-delete-getrandom-o1/solution/cchang-shu-shi-jian-cha-ru-shan-chu-he-huo-qu-sui-/)
    

# Code

```c++
class RandomizedSet {
public:
    vector<int>vec;//随机返回要求存储空间需要连续：本题需要使用vector的数据结构
    unordered_map<int,int>mp;//删除指定val的要求:本题需要使用哈希表

    //哈希表需要实现删除操作的O(1)==>需要快速知道对应val在vector中的下标==>哈希表中键为val，哈希表中的值为val在vector中的下标

    /** Initialize your data structure here. */
    RandomizedSet() {
        

    }
    
    /** Inserts a value to the set. Returns true if the set did not already contain the specified element. */
    bool insert(int val) {//插入vector的同时，更新map
        if(mp.count(val))return false;//包含返回false
        vec.push_back(val);
        mp[val]=vec.size()-1;
        return true;
    }
    
    /** Removes a value from the set. Returns true if the set contained the specified element. */
    bool remove(int val) {//找到下标后，交换到最后删除，同时还要更新map中的键值对
        if(mp.count(val)==0)return false;
        mp[vec[vec.size()-1]]=mp[val];//更新map
        swap(vec[mp[val]],vec[vec.size()-1]);//移动到最后删除
        vec.pop_back();
        mp.erase(val);//更新map
        return true;
    }
    
    /** Get a random element from the set. */
    int getRandom() {
        return vec[rand()%vec.size()];
    }
};

/**
 * Your RandomizedSet object will be instantiated and called as such:
 * RandomizedSet* obj = new RandomizedSet();
 * bool param_1 = obj->insert(val);
 * bool param_2 = obj->remove(val);
 * int param_3 = obj->getRandom();
 */
```
