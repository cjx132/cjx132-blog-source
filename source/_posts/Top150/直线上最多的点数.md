# 综述

[参考题解](https://leetcode-cn.com/problems/max-points-on-a-line/solution/xiang-xi-tong-su-de-si-lu-fen-xi-duo-jie-fa-by--35/)

## 思路：

1.  使用点斜式，遍历每个点，统计经过当前点所组成直线，的最大的点的数目
2.  找出上面的最大值

## 为了写出正确的代码，几个需要注意的点：

1.  map中key的替换方式：使用最大公约数的方法
2.  为了避免约分时除以0的情况（也就是最大公约数为0=>两个数都是0=>两个点重复），需要特殊统计和当前点重复的点的个数，并且要注意，统计完之后，一定要结束本次循环
3.  gcd函数需要使用自己写的，系统自带的有问题
4.  注意代码中的注释，都是易错点

## 回答本题的几个问题：

1.  如果有两条平行直线，那么斜率一样，不就都存到一个哈希key里去了吗？
    
    > 使用点斜式，斜率相同一定是同一条直线，不存在这种情况
    
2.  将键值字符串化很好，可是存在一个问题，如果键值为负比如说（-5/3）（5/-3)这种情况下不是当做两种情况处理了吗，是不是存在bug？
    
    > 不存在。原因：gcd返回的值不一样 （-5/3）返回的是1 （5/-3）返回的是-1。最终存储的还是同一个key
    
3.  为什么不能使用自带的gcd函数
    
    > 尚未明白
    

# Code

```c++
class Solution {
public:
    int maxPoints(vector<vector<int>>& points) {
        int ans=0;
        int n=points.size();
        for(int i=0;i<n;i++){//使用点斜式：遍历每个点
            unordered_map<string,int>mp;
            int curMax=0;//保存经过当前点的直线中，最多的点
            int duplicate=0;//统计和当前点重复的点，也就是下面temp特殊情况的处理方式
            for(int j=i+1;j<n;j++){//从i+1开始
            //求出分子分母
                int d1=points[i][0]-points[j][0];
                int d2=points[i][1]-points[j][1];
                if(d1==0&&d2==0){
                    duplicate++;
                    continue;//不能少，一定要结束本次循环
                }
                //进行约分
                int temp=gcd(d1,d2);
                int a=d1/temp;//这里要防止temp为0（0与0的最大公约数是0，所以这种情况要特殊处理）
                int b=d2/temp;
                //double值不能当做key，使用这种方式替代
                string key=to_string(a)+'/'+to_string(b);
                mp[key]++;
                curMax=max(curMax,mp[key]);
            }
            //1 代表当前考虑的点，duplicate 代表和当前的点重复的点
            ans=max(ans,curMax+duplicate+1);
        }
        return ans;
    }

private:
    int gcd(int a, int b)//使用自己写的
    {
        if (b == 0) {
            return a;
        }

        return gcd(b, a % b);
    }
};
```

# 复杂度分析

-   时间复杂度：O(n^2)
-   空间复杂度：O(m)：m为直线的个数
