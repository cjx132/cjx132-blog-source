# 综述

其实就是转化为严格递增的数组

第一个数一定满足条件，

i从下标1开始枚举每一个数，j表示当前严格递增数组的右端点

当下标i对应的数组值大于下标j对应的数组值，加入i到当前严格递增数组

# Code

```c++
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        //其实就是转化为严格递增的数组
        int n=nums.size();
        if(n<2)return n;

        //nums[0]一定满足条件
        //i从1开始枚举每一个数，每次都拿来和当期满足条件数组的右端点的值比较，如果nums[i]>nums[j]，满足题意，加入
        //j表示存储下来的满足条件数组的最右边数字的下标
        int j=0;
        for(int i=1;i<n;i++)
            if(nums[i]>nums[j])
                nums[++j]=nums[i];

        return j+1;
    }
};
```

# 复杂度分析

-   时间复杂度：O(n)
-   空间复杂度：O(1)
