# 题目

![](/images/Top100/%E5%AD%90%E9%9B%86.png)

# 综述

**枚举每一个数，每个数共有选和不选两种选择**

# Code

```c++
class Solution {
public:
    vector<vector<int>>ans;
    vector<int>tmp;
    vector<vector<int>> subsets(vector<int>& nums) {
        dfs(nums,0);
        return ans;
    }
    void dfs(vector<int>& nums,int u)
    {
        if(u==nums.size())
        {
            ans.push_back(tmp);
            return;
        }

        dfs(nums,u+1);
        tmp.push_back(nums[u]);
        dfs(nums,u+1);
        tmp.pop_back();

    }
};
```

# 复杂度分析

时间复杂度：O(n)

空间复杂度：O(1)
